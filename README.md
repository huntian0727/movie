# 拉面影视 · Movie

免费的 Windows 本地视频管理工具：把硬盘、NAS 和挂载网盘里的视频整理成可搜索、可预览、可播放的资料库，视频保留在原位置。项目早期名称为“映匣”。

## 下载与第一次使用

1. 打开 [v0.1.17 正式发行页](https://github.com/huntian0727/movie/releases/tag/v0.1.17)，下载 **[Movie-0.1.17-Windows-x64-Portable.zip](https://github.com/huntian0727/movie/releases/download/v0.1.17/Movie-0.1.17-Windows-x64-Portable.zip)** 和 `SHA256SUMS.txt`。
2. 按[文件校验说明](docs/windows-installation.md)核对 ZIP 的 SHA-256；校验不符时停止使用。
3. 将 ZIP **完整解压**到自己的程序文件夹，例如 `D:\Apps\Movie-0.1.17`。
4. 双击 **`拉面影视-免费分享版.exe`**。无需安装 Node.js、npm 或单独安装 FFmpeg；播放器运行库已随包提供。
5. 点击右上角 **添加资料库 → 添加本地或挂载目录**，先选择一个小视频文件夹。扫描完成后进入 **视频浏览**，点击封面播放，并试用搜索、收藏和最近播放。

当前正式下载为 Windows x64 **免安装绿色 ZIP**，没有 NSIS 安装器，程序也未做代码签名。不要下载 GitHub 自动生成的 `Source code` ZIP 当作程序，不要直接在压缩软件内运行 EXE，也不需要关闭系统防护来绕过安全提示。

目标平台为 Windows 11 x64。本版使用维护者选择的 Windows 11 Insider Preview 沙盒证据；没有声称已覆盖所有稳定版 Windows、标准用户权限、4K/HDR、长时间压力及真实 CloudDrive/115 永久删除场景。完整范围见[正式发行说明](docs/releases/0.1.17.md)。

## 可以做什么

| 场景 | 功能 |
| --- | --- |
| 整理视频 | 添加目录、递归扫描、文件名搜索、网格/列表、排序和分页 |
| 浏览目录 | 来源总览、目录树、子目录浏览、图片缩略图和大图查看 |
| 日常观看 | 独立播放窗口、进度跳转、音量、全屏、播放列表、收藏、最近播放和字幕搜索 |
| 播放倍速 | 支持 0.5×–5×，包含 3×、4×、5× 高倍速；切换视频时保留倍速选择 |
| 待分析处理 | 可选开启“本页自动分析”（默认关闭）；CloudDrive 暂缓分析与真实失败分开显示 |
| 异常管理 | 按扫描失败、文件缺失、元数据分析失败等原因分类，并与正常后台任务分开 |
| 清理重复 | 按文件大小和四舍五入到整秒的时长筛选候选；按组确认保留项、待清理项和预计回收空间 |
| 后台清理 | 清理任务进入 FIFO 后台队列；可继续浏览和播放，已受理项目暂时隐藏，未知结果不自动重试 |
| 数据管理 | 查看及安全迁移资料库数据目录，并查看离线维护说明 |
| 挂载网盘 | 把 CloudDrive 等挂载盘作为普通目录添加；CloudDrive API 可用于选择远端目录和元数据扫描 |

**关于重复文件清理：**程序只比较精确文件大小和四舍五入到整秒的视频时长，不计算内容哈希；相同大小和时长不保证内容相同。执行前仍会复查路径、大小、修改时间和文件身份，请认真核对保留项。应用内的永久删除会实际删除源文件，且**不进入 Windows 回收站**。

## 数据与文件操作

公开免费分享版的数据目录为 **`%APPDATA%\local-video-manager-community`**，包含 `library.sqlite`、设置、日志及缓存；程序文件夹不包含全部个人数据。开发版和隔离测试版使用不同数据目录，详见[身份对照表](docs/portable.md)。

- 添加目录建立索引；“从资料库移除”移除索引；清理缓存删除可重建预览。这些操作不会因此删除源视频。
- 应用内的移动、重命名和**永久删除**会实际操作源文件；永久删除不进入 Windows 回收站。重复候选只按大小与整秒时长识别，不计算内容哈希。
- 退出后备份整个对应数据目录，原视频另做备份。不同发行身份不自动合并；换电脑或 Windows 用户后，受保护凭据可能需要重新输入。

CloudDrive 与在线字幕是可选联网功能。字幕查询可能发送文件名、关键词或语言等信息；不要公开 Token，诊断资料分享前先审阅。

## 更新与反馈

退出旧程序，将同一发行身份的新版完整解压到新文件夹，核对数据后再移除旧程序目录。当前没有承诺应用内自动更新。[详细升级步骤](docs/portable.md)。

普通问题请附应用版本、Windows 版本、来源类型、复现步骤与脱敏错误信息，提交到 [GitHub Issues](https://github.com/huntian0727/movie/issues)。不要上传 Token、整份数据库或私人视频；安全漏洞按 [SECURITY.md](SECURITY.md) 私人报告。
