# UI Design Review

- [ ] User goal and primary task path remain clear.
- [ ] Navigation and information hierarchy are consistent.
- [ ] Typography, spacing, color, icons, and controls use repeatable rules.
- [ ] Loading, empty, error, offline, pending, disabled, and destructive states are covered.
- [ ] Keyboard, focus, contrast, target size, and readable labels are checked.
- [ ] Dense libraries remain usable at supported window sizes and pagination densities.
- [ ] Destructive actions clearly communicate permanence and scope.
- [ ] Real Electron screenshots and interactions match the approved design.
- [ ] Review returns `UI_REVIEW_PASS` or `UI_REVIEW_FAILED` with prioritized discrepancies.
