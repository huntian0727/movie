# Developer Checklist

- [ ] Read `AGENTS.md`, task packet, affected module README, risks, and recent delivery.
- [ ] Confirm feature branch and preserve unrelated worktree changes.
- [ ] Trace current code, migration, contracts, and tests.
- [ ] Keep scope and out-of-scope boundaries intact.
- [ ] Add/update automated tests for changed behavior and failure paths.
- [ ] Run the task's developer gate and record exact results.
- [ ] Inspect `git diff`, `git diff --check`, and `git status --short`.
- [ ] Update the delivery record and task packet.
- [ ] Return `DEV_COMPLETE` with files, evidence, risks, and QA focus.
