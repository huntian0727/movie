# 验收清单

## 三种入口

- [ ] 文件夹刷新只调用当前文件夹扫描接口
- [ ] 感叹号弹窗只调用异常重试接口
- [ ] 右上角只调用扫描全盘接口
- [ ] 三种入口不是同一个上层 IPC

## 普通扫描

- [ ] 遍历全部目录结构
- [ ] 每一级目录独立建立/比较快照
- [ ] 未变化且无异常目录不读取视频详细属性
- [ ] 深层变化不会因父目录未变而漏掉
- [ ] 目录完整成功后才进行直属缺失对账

## 异常重试

- [ ] 失败文件只重试失败文件
- [ ] 失败目录只重扫该目录子树
- [ ] 不扫描其他正常目录
- [ ] 异常记录跨重启持久化
- [ ] 全部解决后感叹号消失
- [ ] 部分失败时只保留未解决项

## UI

- [ ] 感叹号与正常刷新按钮可同时显示
- [ ] 异常按钮文案为“重试异常项”
- [ ] 右上角文案或 Tooltip 为“扫描全盘”
- [ ] 重复点击不会创建重复任务

## 数据与安全

- [ ] 旧数据库无损迁移
- [ ] 不要求用户清库或重建资料库
- [ ] 根目录离线不清理已有记录
- [ ] 子目录失败不误标视频缺失
- [ ] 中断不提交不完整快照
- [ ] 路径规范化不产生重复记录

## 测试与质量

- [ ] lint 通过
- [ ] typecheck 通过
- [ ] 单元/集成测试通过
- [ ] build 通过
- [ ] Electron smoke/E2E（若项目存在）通过
- [ ] 10,000 文件性能基准执行并有真实结果
- [ ] 无 TODO、占位实现、调试代码
- [ ] 未覆盖原有未提交修改
