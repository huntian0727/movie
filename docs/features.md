# 本地视频管理工具功能文档

## 目标

构建一个本地桌面端视频管理工具，用于添加本地文件夹、浏览视频、预览封面、播放视频、收藏、删除、重命名、分页浏览和查看最近播放历史。

## 功能范围与验收标准

### 1. 文件夹导入

**预期行为**
- 用户可以选择本地文件夹添加到资料库。
- 支持递归扫描，可在设置中配置默认是否递归。
- 扫描识别主流视频扩展名：`.mp4`, `.mkv`, `.avi`, `.mov`, `.flv`, `.webm`, `.wmv`, `.m4v`, `.ts`。
- 扫描时读取视频大小、时长、分辨率、格式、修改时间。
- 同一路径重复扫描应更新元数据，不重复创建记录。
- 文件未变化时重复扫描不应重复执行昂贵的元数据读取。
- 文件消失时标记为缺失，而不是静默保留在普通列表中。
- 左侧刷新只扫描当前源目录；异常弹窗只重试持久化失败项；右上角“扫描全盘”按顺序扫描所有启用目录。
- 每目录直属快照用于避免未变化视频的逐文件属性读取；父目录未变化仍会检查深层子目录。
- 根目录离线、子目录超时/权限失败或任务取消时，不把未完整枚举范围误判为删除。

**验收标准**
- 添加文件夹后视频出现在列表。
- 重新扫描同一文件夹不会产生重复记录。
- 删除磁盘文件后重新扫描，该记录标记为缺失并从普通列表/播放队列过滤；当前设置页不提供缺失记录管理入口。
- 启动同步或手动同步不会导致明显卡顿。

### 2. 视频列表

**预期行为**
- 展示视频文件名、大小、时长、分辨率或格式。
- 支持网格视图和列表视图。
- 支持按文件名、大小、时长、修改时间排序。
- 支持升序/降序切换。
- 支持按文件名搜索。
- 支持按所有视频、收藏、最近播放、单个文件夹切换视图。

**验收标准**
- 搜索、排序、视图切换后列表结果正确。
- 空列表、加载中、错误状态有明确显示。
- 大量视频时主窗口内存稳定，不一次性渲染全库。

### 3. 分页

**预期行为**
- 列表分页显示。
- 默认每页 100 个视频。
- 每页数量可切换为 30、50、100、200、300。
- 支持上一页、下一页、页码输入和当前页/总页数展示；页码可按 Enter 或失焦提交，越界自动限制到有效范围。
- 非输入和非弹窗状态下，键盘左/右键切换上一页/下一页。
- 搜索、排序、视图、文件夹、每页数量变化后回到第一页。
- 翻页或切换每页数量后内容区回到顶部。

**验收标准**
- 超过 100 条时默认只展示第一页。
- 切到下一页后展示后续视频。
- 切换每页数量后页数重新计算。
- 搜索框、页码框、下拉框或弹窗激活时，左右键不会误翻页。

### 3.1 网格预览大小

**当前行为**
- 网格视图支持 180、220、260、320、400px 五档目标卡片宽度，并根据窗口宽度自动计算瀑布流列数。
- 可通过工具栏减号、滑条和加号调整；列表视图和重复项页面不显示该控件。
- 选择保存在 renderer `localStorage`，重新打开应用后恢复；调整大小不改变筛选、排序或当前页。

### 4. 视频封面预览

**预期行为**
- 视频网格卡片展示预览封面。
- 封面按需生成，仅生成当前需要显示的视频。
- 封面生成结果缓存到本地缓存目录。
- 缓存目录为应用用户数据中的 `media-cache`，采用 10 GiB 总上限、分类配额、365 天 TTL 和近似 LRU 的有界长期保留策略；用户也可在设置页手动清理。
- 同一视频未变化时重复打开不重复生成封面。
- 视频路径、大小或修改时间变化后缓存自动失效并重新生成。
- 封面生成失败时显示默认占位，不影响列表浏览。

**验收标准**
- 首次展示视频时可生成封面。
- 第二次展示同一视频时命中缓存。
- 缓存目录清理后可重新生成。
- 封面生成慢或失败时 UI 不阻塞。

### 5. 播放窗口

**预期行为**
- 点击视频播放时打开独立播放窗口。
- 主窗口保持视频库列表，不切换到播放器页面。
- 播放窗口复用：再次点击其他视频时复用同一个播放窗口并替换播放内容。
- 播放窗口支持上一部/下一部，队列来自当前筛选排序后的结果。
- 播放窗口关闭不影响主窗口。

**验收标准**
- 点击播放后出现独立窗口。
- 主窗口仍停留在视频库。
- 再点击另一个视频时不会无限创建窗口。
- 上一部/下一部按当前列表顺序切换。

### 6. 播放能力

**预期行为**
- 对 Chromium 原生可靠格式使用内置播放器，例如 `.mp4`, `.m4v`, `.webm`, `.mov`。
- 当前播放链路为 Chromium 原生播放器 → mpv → 系统默认播放器 fallback。
- 对 `.mkv`, `.avi` 等不适合 Chromium 原生播放的格式优先使用 mpv。
- 用户可在设置中选择自动、优先内置、优先 mpv。
- 原生播放失败时自动尝试 mpv。
- mpv 启动失败时通过 Electron `shell.openPath` 尝试系统默认播放器；仅当系统也无法打开时显示组合错误，不影响应用其他功能。

**验收标准**
- 可播放原生支持格式。
- 不兼容格式不应在内置播放器里无响应。
- mpv 未安装时会尝试系统默认播放器；无可用系统文件关联时错误可见。

### 7. 播放控制

**预期行为**
- 支持播放/暂停。
- 支持快进/快退，秒数来自设置。
- 支持音量调整和静音。
- 支持上一部/下一部。
- 支持收藏/取消收藏。
- 支持全屏。
- 默认支持空格、方向键和 `Ctrl+D` 等控制；视频库与播放器快捷键可在设置页重新绑定。

**验收标准**
- 各控制按钮状态正确。
- 禁用状态明确，例如没有上一部时上一部按钮禁用。
- 收藏状态能同步回资料库。

### 8. 进度条 hover 预览

**预期行为**
- 鼠标悬停在进度条上时显示对应时间。
- 如果预览帧存在或可生成，显示对应画面。
- 预览帧按固定时间粒度缓存，避免鼠标移动时频繁生成。
- 生成失败时仍显示时间，不显示破图，不影响播放。

**验收标准**
- hover 位置与时间计算正确。
- 预览图片请求 URL 合法。
- 缓存命中后不重复生成。
- 失败降级不影响播放。

### 9. 收藏

**预期行为**
- 用户可在列表或播放器中收藏/取消收藏视频。
- 收藏视图只展示收藏视频。
- 收藏状态持久化。

**验收标准**
- 收藏后切到收藏视图可见。
- 取消收藏后从收藏视图消失。
- 重新启动应用后状态仍保留。

### 10. 删除、重命名与安全移动

**预期行为**
- 用户可重命名视频文件，扩展名保持不变。
- 重命名不会通过创建目标占位文件抢占名称；目标已存在时返回冲突，不覆盖目标。
- Windows 仅大小写变化使用同目录临时名称分两步完成；第二步失败时恢复原名称，不留下零字节占位文件。
- 用户可永久删除视频文件。
- 删除前必须确认。
- 删除或重命名后数据库记录同步更新。
- 当前页可多选视频并批量移动到其他受管目录；目标目录可在确认后加入资料库。
- 同名目标无论大小是否相同都不会被自动覆盖，使用 `文件名1.ext`、`文件名2.ext` 依次寻找可用名称。
- 同卷移动先排他创建目标身份，再删除源；跨卷移动先复制到应用专用临时文件，校验源版本和复制大小，安全发布目标后才删除源。
- 文件成功移动但数据库更新失败时，应用尝试将文件恢复到原路径；若原路径已被其他文件占用，两份文件都保留并报告人工处理错误。

**验收标准**
- 重命名后磁盘文件名和列表显示一致。
- 重命名失败或数据库更新失败时，旧名称可恢复且数据库不指向不存在的文件。
- 删除后磁盘文件和列表记录都移除。
- 操作失败时显示错误。
- 同名同大小但内容不同的文件移动后两份都保留。
- 复制、发布、删除源或数据库更新任一步失败时，不删除既有目标；结果逐项返回最终路径、实际策略和错误码。

### 11. 最近播放

**预期行为**
- 每次开始播放时记录最近播放。
- 同一个视频只保留最新一条记录。
- 最近播放按播放时间倒序。
- 侧边栏提供“最近播放”视图。

**验收标准**
- 播放视频后出现在最近播放。
- 重复播放同一个视频不会出现重复条目。
- 再播放其他视频后顺序更新。

### 12. 设置与维护

**预期行为**
- 设置默认递归扫描。
- 设置启动时自动同步。
- 设置快进/快退秒数。
- 设置播放策略。
- 显示缓存位置。
- 支持清理缓存。
- 清理只作用于 `media-cache` 中的业务预览，不作用于 Electron 自身缓存；旧版 `Cache/covers` 与 `Cache/timeline` 在启动时安全迁移。
- 列出并修改视频库翻页、播放器播放/暂停、快进/快退、音量、旋转和永久删除快捷键；同一页面内不能重复。
- 支持先预览再导出脱敏诊断 JSON；默认不含完整应用目录，始终不含视频、数据库正文、令牌或环境变量值。

**验收标准**
- 设置修改后持久化。
- 清理缓存后缓存目录被清空并重建。
- 快捷键修改后持久化，并同步到已打开的播放器窗口。
- 诊断预览与导出内容一致；播放器窗口不能调用诊断接口。

### 13. 安全重复项识别与分页

**当前行为**
- 重复项按数据库中已经缓存的精确文件大小和时长分组；打开或刷新页面不会主动读取网盘视频、生成快速指纹或计算完整哈希。
- 确认删除和实际执行时，主进程分别重新读取数据库，并复查保留项与拟删除项的路径、大小和修改时间；发生变化会中止对应操作，但不会读取文件内容。
- renderer 传入的 `size-duration:*`、伪造 group key、保留 ID 或删除 ID 不能绕过主进程按数据库记录重新构建重复组。
- 只有进入重复项页面时才查询 SQLite，普通资料库刷新不会加载全部重复组。
- 重复组按文件大小全局升序或降序，并在数据库中按 10/20/50 组分页，默认每页 20 组。
- 单项永久删除后刷新当前页；批量清理只处理当前页大小与缓存时长完全一致、并在确认阶段完成文件存在性、大小和修改时间复查的组。
- 删除导致末页消失时，服务端校正到新的最后一页。

**验收标准**
- 大量重复候选不会一次性传输或渲染到页面。
- 跨页大小排序正确，切换页码和每页数量不会丢失全局统计。
- 未查看页面不会被当前页批量清理静默处理。
- 大小和时长一致只是低带宽候选规则，不能证明内容完全相同；界面必须保留风险提示、播放入口和永久删除确认。

## 非目标

- 不做云同步。
- 不转码视频。
- 不移动原始文件到应用私有目录。
- 不实现多用户权限。
