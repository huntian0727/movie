# 拉面影视 0.1.16 · Windows x64 绿色版

本次计划版本：2026-10-19。基于 v0.1.15 以来已完成的更新。正式程序与校验文件将在版本对应的 GitHub Release 提供。

[下载与发行状态](https://github.com/huntian0727/movie/releases/tag/v0.1.16) · [本版本完整使用教程](../user-guide/0.1.16.md) · [变更记录](../../CHANGELOG.md) · [校验教程](../windows-installation.md)

## 新增与修复

1. **异常中心更容易理解。** “需要处理”将扫描失败、文件缺失、元数据分析失败按原因分类；来源错误聚合展示，优先检查网络、路径和权限，不把同一来源的多条记录说成多个独立故障。
2. **30 万级正常任务不再算异常。** CloudDrive 为避免远端读取压力而暂缓的元数据分析放进“后台任务”；分析失败与暂缓分析默认使用不同筛选入口，正常暂缓无须全部重试。
3. **安全批量操作与处理历史。** 批量复查和元数据分析先预览范围再确认，可跟踪进度、取消、查看成功/跳过/失败记录；重启后未完成任务标记为意外中断。不自动清除错误以制造零异常。
4. **资料库数据目录可管理。** 设置中查看现有目录、离线阅读目录说明，并通过完整复制与校验迁移数据库、设置、应用字幕和媒体缓存；源视频不移动。
5. **CloudDrive API 配置快捷入口。** 添加 API 目录时可直接前往配置，并在返回后刷新来源。
6. 修正异常中心总览布局、中文错误摘要和来源统计说明，避免标题被导航覆盖。

## 获取与升级

- 公开范围为 Windows 11 x64 **免安装绿色 ZIP**，不发布 NSIS 安装器。下载文件名为 Movie-0.1.16-Windows-x64-Portable.zip；同时下载 SHA256SUMS.txt 并核对。该发行身份没有代码签名。
- 先完全退出旧程序，备份整个社区版资料库（默认为 %APPDATA%\local-video-manager-community）和迁移后的定位文件。把新版完整解压到**新的程序目录**，启动“拉面影视-免费分享版.exe”；确认资料库、来源、收藏与历史仍在之后再清理旧程序文件夹。
- 本版批量处理历史使用数据库 schema v16。升级前备份，升级后不要再用旧程序反复打开更新过的资料库。不同发行身份（社区 / 本地开发 / 隔离测试）的资料库互不自动合并。
- 对 CloudDrive 远端视频不要一次性触发海量媒体分析；按需处理个别视频，可能产生网络流量。永久删除直接作用于真实文件，必须审阅证据、通过安全检查并做好备份。
