# 拉面影视 0.1.16 正式发行说明

> 发行范围：Windows x64 未签名绿色 ZIP。不发布 NSIS 安装器或签名版。本版技术包版本为 0.1.16，界面版本为 v1.6。

- 下载程序：Movie-0.1.16-Windows-x64-Portable.zip
- 校验清单：SHA256SUMS.txt
- 精确应用源码：Movie-0.1.16-Application-Sources.zip
- 对应原生源码：Movie-Native-Runtime-0.1.16-Corresponding-Sources.zip
- 配对与最终验证：SOURCE-PAIR.json、RELEASE-VERIFICATION.json、build-metadata.json
- 完整使用教程：docs/user-guide/0.1.16.md；滚动教程：docs/USER_GUIDE.md；文件校验教程：docs/windows-installation.md

## 相较 v0.1.15 的改进分类

### 1. 安全类

- 重复文件清理在提交前重新核对路径、大小、时长、修改时间、文件身份与任务占用；保留文件与待删文件冲突时阻止操作。
- 清理任务按 FIFO 队列后台执行。网盘调用断连或程序异常退出时，明确区分已成功、当前结果未知和后续未提交项目；未知删除不自动重试。
- 按重复组清理前重新核对组成员，只有完整目标列表被队列接受后才隐藏该组；普通删除通道仍阻止未经专门复核的重复候选。
- 资料库数据目录迁移先校验目标，再切换数据库、设置、字幕和媒体缓存位置；源视频文件保持原位置。
- 本次发行固定使用已核验的第三方运行库/源码配对，并为新构建的 NativeHost 绑定源码和二进制哈希；不把候选包冒充正式包。

### 2. 性能类

- 视频页新增默认关闭的“开启本页自动分析”，只按当前页按需请求元数据；翻页、筛选、切换目录、离开模块或关闭开关时取消尚未启动的旧页面请求，不默认扫描整个远端资料库。
- CloudDrive 暂缓分析与真实分析失败分开呈现，避免把正常等待误报为异常或反复重试。
- 重复目录清理合并远端身份核对，独立请求按小批次提交；清理任务在后台运行，不阻塞页面切换与播放器。
- 重复项已受理清理后临时隐藏待删项；正常完成后刷新索引，状态条只在重复文件页显示且会自动消失。

### 3. 功能增加类

- 播放器支持 3×、4×、5× 高倍速，并保留原有 0.5×–2× 选项；浏览器播放器与内嵌 MPV 使用一致的速度范围，切换视频时保留所选倍速。
- 主界面标题旁显示两段式界面版本号 v1.6，与技术包版本 0.1.16 分开。
- 新增按重复组确认清理：确认框展示保留项、待清理项和预计回收空间，提交后按队列执行。
- 异常中心按扫描失败、文件缺失、元数据分析失败等原因分类；来源级问题聚合，减少重复噪声。
- 增加批量操作历史、清理结果摘要、数据目录迁移帮助及 CloudDrive API 配置快捷入口。

### 4. 修复与体验改进

- 播放窗口已打开时，从主窗口选择另一部视频会切换到新视频，而不是只唤起旧窗口。
- 清理任务被接受后，列表立即隐藏已入队待删文件；整页清理覆盖当前目录所有候选组时自动退出该目录筛选，但保留“优先保留此目录”偏好。
- 部分失败、结果未知和异常中断继续保留可见记录，方便人工核对，不会伪装成清理成功。

## 升级建议

完全退出旧程序后，将 ZIP 解压到一个新的程序目录再启动。不要删除原视频或社区资料库目录。默认社区资料库位于 %APPDATA%\local-video-manager-community；不同发行身份的资料库不会自动合并。
