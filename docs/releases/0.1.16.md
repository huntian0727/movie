## 候选新增与修复

1. **异常中心更容易理解。** “需要处理”将扫描失败、文件缺失、元数据分析失败按原因分类；来源级问题聚合展示，避免把同一来源的大量记录误解为同样多的独立故障。
2. **正常暂缓任务与异常分离。** CloudDrive 为避免远端读取压力而暂缓的元数据分析放入“后台任务”；分析失败与暂缓分析使用不同入口。正常暂缓无须全部重试。
3. **批量操作历史与安全边界。** 批量操作先确认处理范围，记录成功、跳过、失败与摘要；未完成任务在重启后标记为意外中断，不自动重试。
4. **资料库数据目录管理。** 可查看目录说明、迁移数据库、设置、应用字幕与媒体缓存；迁移通过校验后切换目录，源视频保持原位置。
5. **CloudDrive API 配置快捷入口。** 添加 API 目录时可直接定位设置，返回后刷新来源。
6. **本页自动分析。** 视频浏览提供默认关闭的“开启本页自动分析”，只按当前页按需请求元数据；翻页、筛选、切换目录、离开模块或关闭开关时取消旧页面尚未启动的专属请求，不会默认扫描整个远端资料库。
7. **界面版本可见。** 主界面标题旁显示两段式界面版本号；本候选目标为 `v1.2`，与技术包版本 `0.1.16` 分开管理。
8. **播放器切换修复。** 播放窗口已打开时，从主窗口选择另一部视频会同步切换到新视频，不再只唤起旧窗口。
9. **重复文件清理安全与交互改进。** 继续使用低带宽判定：精确文件大小相同且视频时长四舍五入到整秒后相同；不读取完整视频，也不计算内容哈希。执行前重新检查路径、大小、时长、修改时间、文件身份及任务占用。
10. **后台清理状态更清楚。** 单文件或“清理当前页”被正式受理后，待删项从列表临时隐藏，同组保留文件不隐藏；任务结束刷新索引，明确失败、未知和未提交项重新呈现。整页恰好覆盖选定目录中的全部候选组时自动退出该目录浏览筛选，但保留“优先保留此目录”偏好；多页只清理当前页不会自动跳走。
11. **中断不自动重放。** 后台清理按批次推进，保留成功结果；网盘调用断连或程序意外退出时，将当前未知与后续未提交项目分开记录，不自动重试未知删除请求。
12. **重复清理提速与防护。** 合并重复目录的远端身份核对，按小批次并行提交独立请求；普通删除通道仍阻止未经专门复核的重复候选，保留文件和受管路径检查不因提速绕过。

正式批准后，目标发布范围为 Windows x64 **免安装绿色 ZIP**，不发布 NSIS 安装器。届时需在同一 GitHub Release 提供候选程序、SHA-256 校验清单、实际验证记录和获准公开的源码/许可材料。当前这些链接及附件尚未发布。

永久删除直接作用于真实文件，不进入 Windows 回收站。重复候选的大小和时长相同不代表内容相同，必须仔细检查保留项与待删项。

## 公开发行仍然阻塞

下列事项不能通过修改测试、重写批准文件或更换包名绕过：

1. **批准记录与当前候选不匹配。** 当前技术版本为 0.1.16，历史正式批准记录仍绑定 0.1.15，当前 `package-lock.json` 的 SHA-256 也与批准记录不同；需要对精确候选重新审核并记录新的真实批准。
2. **原生媒体许可与分发审批未完成。** FFmpeg Lite 当前锁文件仍标记为 `CANDIDATE_NOT_APPROVED` / `distributable: false`。静态链接的 LGPL 重链接义务和组件级许可处置尚未最终签核。
3. **稳定 Windows / 标准用户覆盖不足。** 已有隔离沙盒证据只覆盖其实际声明的范围，尚不能声称稳定 Windows 11 与标准用户策略均已实测并获所有者验收。
4. **真实 CloudDrive/115 删除回归未执行。** 用户已明确暂缓真实删除验收；不得擅自在真实影视资料库中试删。公开前需要在获准的隔离测试文件上完成远端行为验收，或明确决定该项的发行处理方式。
5. **人工体验尚未完成。** 播放器切换、字幕匹配与下载、安装后实际使用仍需最终人工验收；自动化测试不能替代真实用户体验确认。
