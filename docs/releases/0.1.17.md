> **发布范围：Windows x64 未签名绿色 ZIP。** 本版技术包版本为 0.1.17，程序界面版本为 v1.43。仅发布免安装 ZIP，不发布 NSIS 安装器、不提供签名版，也不启用旧生产身份升级。

## 相较 v0.1.16 的改进

### 安全类

- 重复清理继续在执行前复核路径、文件大小、视频时长（四舍五入到整秒）、修改时间、文件身份和任务占用。已受理任务进入后台 FIFO 队列；成功、明确失败、结果未知和未提交项目分开记录，结果未知时不自动重试。
- 数据库迁移备份采用暂存、只读打开和完整性检查后再发布正式备份的流程；备份失败时停止迁移。启动时不会自动续跑上次异常中断的扫描。
- 新增 Schema 17、18、19 的视频排序索引迁移及回滚/查询计划回归覆盖，改善大资料库排序，同时保留现有资料库和文件操作安全约束。
- 原生运行库继续使用固定版本的第三方运行库与对应源码材料；38 个第三方 PE 维持已核验字节。本版仅重新确定性构建项目自有 MIT NativeHost，并在对应源码附件中提供当前源码与固定编译工具/引用信息。
- 本版未签名。永久删除仍直接作用于真实文件、不进入 Windows 回收站；真实 CloudDrive/115 永久删除回归不属于本次声明的验收范围。

### 性能类

- 10,000 个重复候选项的 Electron 合成滚动测试定位并修复行级 React 重渲染热点。窗口化开启时，三轮 p95 从修复前的 49.9–58.4 ms 降至 16.7 ms；三轮均未出现超过 33 ms 的帧间隔，昂贵行内容峰值挂载 28 个。该结果来自隔离 Electron renderer 测量，不等于真实硬件 FPS 或物理滚轮延迟。
- 10,000 文件的单个重复组查询从修复前平均约 9,247 ms 降至约 56.55 ms，约快 163 倍；保留文件大小与时长判重口径。
- 100,000 条合成元数据队列任务的吞吐约为每秒 14,398–14,950 条，测试期间最大事件循环间隔约 17.75–19.49 ms；停止、重试与暂停/恢复行为有回归覆盖。
- 新增视频数据排序索引、可视区域窗口化与后台查询调度，减少大列表 DOM、IPC 传输和主事件循环的无效工作。

### 功能增加类

- 新增后台任务中心，用于集中查看扫描、元数据、重复清理和缓存生成等任务状态；“待处理（含暂缓）”与“分析失败”分开显示，避免把正常暂缓误报为故障。
- 视频浏览支持默认关闭的“本页自动分析”，只按当前页请求元数据；翻页、筛选、切换目录、离开模块或关闭功能时会停止旧页面尚未启动的请求。
- 重复清理支持独立任务排队，受理后暂时隐藏待清理项，并在任务结束后按实际结果刷新；当前页清理覆盖所选目录的全部候选组时会自动退出该目录筛选。
- 播放器支持 3×、4×、5× 倍速，并修复长按临时快进后松开恢复原速度、切换播放内容和焦点线残留等体验问题。
- 标题旁的界面版本号为 v1.43，与技术包版本 0.1.17 独立管理。

最终发布的准确提交 SHA、Windows CI、安全审计、源码配对构建运行、原生组件哈希、ZIP 哈希和附件配对结果以本 Release 的 RELEASE-VERIFICATION.json 与 SHA256SUMS.txt 为准。任何一项门禁未通过，都不应将草稿公开为 Latest。

本版声明范围为 Windows x64 未签名绿色 ZIP。没有声称已覆盖所有稳定版 Windows、标准用户权限、4K/HDR、长时间压力或真实 CloudDrive/115 永久删除场景。程序未签名，Windows 可能显示来源/安全提示；请核对发布页的 SHA-256，不要关闭系统防护来绕过警告。

## 升级建议

1. 从本 Release 下载绿色 ZIP 和 SHA256SUMS.txt，并先核对 ZIP 的 SHA-256。
2. 完整解压到普通程序目录；不要只复制 EXE，也不要直接在压缩软件内运行。
3. 升级前备份应用数据目录。首次启动时，程序会按自身迁移流程处理数据库版本；如果迁移备份或完整性检查失败，应停止操作并保留原数据。
4. 本版不执行自动全库扫描，也不会自动重放结果未知的删除请求。首次使用建议先选择一个小目录检查浏览、播放与任务状态。
