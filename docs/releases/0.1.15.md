# 拉面影视 0.1.15

Windows x64 正式绿色版，免费开源，解压后运行“拉面影视-免费分享版.exe”。无需安装 Node.js 或单独配置 FFmpeg。程序未做代码签名。

下载 Movie-0.1.15-Windows-x64-Portable.zip；校验文件为 SHA256SUMS.txt。更新前关闭旧版本，将新版解压到新目录运行；社区资料库沿用用户目录 local-video-manager-community，不要删除资料库或原视频。

## 验证范围

根据维护者明确选择，本次正式版使用 Windows 11 Enterprise Insider Preview 26100.9606、AMD64、默认沙盒账号验收。已验证目录扫描、缩略图、H.264/AAC、H.265/AAC、H.265/DTS MKV、VP9/Opus MKV、真实 2560×1440 H.265/PCM A-law，暂停/跳转/继续播放、重启保留数据以及移动/移除绿色程序后数据保留。声音确认复用相同 SHA-256 的 39 个原生文件，不声称每个新 ZIP 都重新听测。最终 ZIP 的对应 CI、安全检查、源码与许可一致性、打包 smoke 和沙盒 GUI 结果见 RELEASE-VERIFICATION.json。

未覆盖普通标准用户、4K/HDR、长时间压力、NSIS 安装/卸载、SmartScreen 首次下载、签名升级。正式发行不代表全部 Windows 环境均已验证。
