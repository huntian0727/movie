# 拉面影视 0.1.16-beta.1（公开预发布）

> **公开测试版，不是稳定版。** Windows x64 绿色 ZIP，无安装器、未签名。稳定版仍为 [v0.1.15](https://github.com/huntian0727/movie/releases/tag/v0.1.15)。

## 本版更新

- 界面版本更新至 **v1.6**。
- 播放器新增 3×、4×、5×倍速，HTML5 与内嵌 MPV 使用一致的速度范围；切换视频时保留当前选择。
- 修复播放器已打开时选择另一部视频却未切换播放的问题。
- 改进重复文件后台清理队列、按重复组清理、受理后暂时隐藏已入队项目、进度提示及未知结果处理。
- 优化异常中心分类、待分析状态、批量操作记录与后台任务交互。

## 下载与使用

下载本页 Movie-0.1.16-beta.1-Windows-x64-Portable.zip，完整解压到一个新目录后运行 拉面影视.exe。本版不提供安装器或签名升级。社区版资料库与本地开发版资料库隔离；不要覆盖旧程序目录后直接删除旧版数据。

请核对 SHA256SUMS.txt。同一 Release 提供应用源码、对应原生运行库源码和许可材料。

## 预发布范围和注意事项

本版本复用已核准的第三方运行库批次；唯一变更的原生 PE 是项目自有 MIT NativeHost，用于播放器倍速。Windows CI、安全审查、打包文件校验和实际打包程序 smoke 已通过。

以下项目仍未认证：稳定 Windows 11 与标准用户权限、签名安装/升级、长期负载、4K/HDR，以及真实 CloudDrive/115 资料库的破坏性删除回归。后台清理会永久删除文件。首次使用前请备份资料库和重要视频，并先在可恢复的测试目录验证；未知删除结果不会自动重试。此预发布版不应作为唯一数据副本或稳定生产版使用。
