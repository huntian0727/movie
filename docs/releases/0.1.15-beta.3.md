# 拉面影视 0.1.15-beta.3 — 首个公开测试版

免费、开源的 Windows x64 本地视频管理工具。本版本提供绿色 ZIP：完整解压后双击 `拉面影视-免费分享版.exe`，无需安装 Node.js、FFmpeg 或配置开发环境。程序未签名；这是 GitHub **预发布测试版**。

本版修复内嵌播放黑屏/解码兼容问题，使用固定源码构建的媒体和播放器运行库，并补齐逐文件版权声明、对应源码、构建和工具链材料。

## 下载与使用

- 程序：`Movie-0.1.15-beta.3-Windows-x64-Portable.zip`。不要在 ZIP 内直接运行，也不要只复制 EXE。包内程序仍为 `拉面影视-免费分享版.exe`，下载文件名使用英文以兼容 GitHub 的资产命名规则。
- 应用对应源码：`Movie-0.1.15-beta.3-Application-Sources.zip`。
- 原生组件对应源码、许可证及构建材料：`Movie-Native-Runtime-38134981406-Corresponding-Sources.zip`。
- 校验和：`SHA256SUMS.txt`；同页所有材料免费提供。

原生运行库仍为固定生产批次 `38134981406`，39 个原生文件未变。原生源码归档从 `ff4c378` 审阅基线复用，包含当时的 beta.1 审阅元数据；其原生批准文件与本版完全一致。`Movie-0.1.15-beta.1-Application-Sources.zip` 保留为该审阅基线源码，**本版应用准确源码是 beta.3 的 Application-Sources.zip**。`SOURCE-PAIR.json` 映射本版应用 commit 与不变的原生源码/运行库哈希；不把基线应用源码冒充当前版本。

资料库保存在 `%APPDATA%\local-video-manager-community`。更新时关闭旧程序，将新版完整解压到新目录后启动即可沿用社区版资料库；建议先备份该数据目录。删除程序文件夹不会删除资料库或源视频。旧日常版资料库与社区版分开，本版不承诺自动迁移旧版数据。

## 实际验证范围

人工验收环境：**本机 Windows Sandbox，Windows 11 Enterprise Insider Preview 26100.9606，AMD64，默认沙盒账号**。

已观察首次启动、目录扫描、缩略图、暂停、跳转、恢复播放、重启后资料库/播放进度保存、移动绿色程序，以及删除程序后保留资料库和原视频。H.264/AAC MP4、H.265/AAC MP4、H.265/DTS MKV、VP9/Opus MKV 均有活动画面，用户确认声音正常；真实 2560×1440 H.265 / PCM A-law 视频也有正常画面和声音。

人工声音结果对应先前云端 QA 包的固定原生运行库；本次最终包须核对 39 个原生 PE 的 SHA-256 完全一致，并另做对应 commit 的 CI、依赖安全检查、解压与打包 smoke、许可文件字节一致性检查。不会将先前人工测试写成每个新 ZIP 都重新听测。

尚未覆盖：稳定版 Windows 11、普通标准用户权限、NSIS 安装/卸载、SmartScreen 首次下载体验、签名升级、4K/HDR、长时间负载和全部时间轴后台任务。仅发布绿色测试包，稳定正式版批准仍关闭。
