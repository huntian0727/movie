## 1. 下载和启动

打开 [正式版下载页](https://github.com/huntian0727/movie/releases/tag/v0.1.15)，下载 **`Movie-0.1.15-Windows-x64-Portable.zip`** 和 **`SHA256SUMS.txt`**。

带 `Application-Sources`、`Corresponding-Sources` 或 GitHub 自动生成的 `Source code` 是源码材料，普通使用无需编译它们。`beta` 是公开测试版，`unsigned-test-build` 是隔离测试身份；不同身份不能当成同一程序覆盖升级。

1. 按 [文件校验说明](../windows-installation.md)核对 ZIP。
2. 完整解压到自己的普通文件夹，例如 `D:\Apps\Movie-0.1.15`。
3. 双击 **`拉面影视-免费分享版.exe`**；可自行为它创建桌面快捷方式。

保留 `resources`、DLL 等配套文件，不要只拿走 EXE，也不要直接在压缩软件内运行。无需另装 Node.js、npm、FFmpeg 或手工寻找播放器 DLL。CloudDrive 属于网盘场景可选的独立软件，本地视频不需要它。

当前发布目标为 Windows 11 x64，实际验收使用 Windows 11 Insider Preview 沙盒。安装器、Windows ARM、其他系统和全部硬件组合未作统一兼容保证。包未签名；核实来源与哈希，出现安全拦截时反馈维护者，不需要关闭系统防护。

## 2. 第一次添加视频

先用一个含几段视频的小文件夹熟悉操作：

1. 点击右上角 **添加资料库 → 添加本地或挂载目录**。
2. 在 Windows 文件夹选择窗口中选择目录，例如 `D:\Videos\示例`。
3. 默认递归扫描子文件夹；**设置 → 资料库 → 默认递归扫描** 可调整以后添加目录的默认行为。
4. 等待 **资产中心 → 扫描状态** 或来源状态完成。扫描、元数据分析和预览生成是不同阶段，缩略图与时长可能稍后出现。
5. 左侧选择 **视频浏览**，点击封面播放；试一下收藏和最近播放。
6. 退出后重开，确认目录、索引和个人记录保留。

添加目录建立本机索引，原视频保留原位置，不会把整个视频文件夹复制到程序目录。可识别后缀为 `MP4、MKV、AVI、MOV、FLV、WEBM、WMV、M4V、TS`；识别后缀不等于所有编码组合都能播放。

## 3. 各种目录添加方式怎么选

| 视频在哪里 | 添加方式 | 需要准备 | 区别 |
| --- | --- | --- | --- |
| 本机、移动硬盘 | 添加本地或挂载目录 | Windows 可访问目录 | 普通文件夹扫描，使用直接 |
| NAS / SMB | 添加本地或挂载目录，选择盘符或 `\\NAS\Video` | 先在 Windows 确认连接与权限 | 索引在本机，扫描和播放依赖网络与共享权限 |
| 已挂载网盘 | 添加本地或挂载目录，例如 `F:\视频` | CloudDrive 等已登录、绑定并挂载 | 走 Windows 目录入口；配置了匹配的 CloudDrive API 时，扫描器可利用 API 加速 |
| CloudDrive API 目录 | 通过 CloudDrive API 添加 | 地址、Token、可访问的挂载路径 | 逐层浏览远端目录、保存远端身份；目录枚举避免逐视频读取本地属性 |

两种 CloudDrive 入口的重点是如何选目录、是否保存远端身份及扫描条件。API 不会把所有视频复制进程序，也不代表不用挂载就能播放。预览、媒体分析和播放仍可能读取内容并产生网盘流量。

普通添加窗口以**目录**为单位；目前不提供把单个视频、ZIP、网盘分享链接或任意播放 URL 当成资料库导入的入口。目录树拖动调整显示顺序，不是拖入视频文件导入。

先选择真正的视频目录，确认结果后再扩大范围，避免一开始添加整个系统盘或全部网盘根目录。

## 4. 115 与 CloudDrive API

### 先准备网盘挂载

1. 在自己的电脑安装并运行 CloudDrive，按提示登录、绑定 115。
2. 完成挂载，确认 Windows 资源管理器能打开测试视频目录，例如 `F:\测试视频`。
3. 先选少量文件测试。CloudDrive 的服务、会员、流量或提供方限制由对应软件与网盘决定。

Movie 不内置 115 登录，也不会替你申请 Token。[CloudDrive 官方帮助](https://www.clouddrive2.com/help.html)提供服务安装、绑定、挂载和 API 说明。

### 配置连接并添加

**正式版 0.1.15：**右上角 **设置 → CloudDrive API**。

| 配置项 | 填写方法 |
| --- | --- |
| API 地址 | Movie 与 CloudDrive Core 同机时常见为 `http://127.0.0.1:19798`，以实际服务地址为准 |
| API Token | 从 CloudDrive API 令牌管理取得，只填程序，不发到聊天或公开 Issue |
| 请求超时 | 默认 `20000` 毫秒，先保留默认 |
| 手动挂载映射 | 通常留空，自动读取挂载点；自动路径不正确时才填写 |

1. 填写后点击 **保存并测试连接**。
2. 成功后返回，点击 **添加资料库 → 通过 CloudDrive API 添加**。
3. 选择挂载来源，逐层打开目标目录，核对远端与本地路径。
4. 点击 **添加并扫描此目录**，查看扫描结果。

Token 已配置时，替换框留空会保留现有 Token；输入新值再保存才会替换。保存的明文不会重新显示。

### 容易混淆的情况

- **本机与沙盒：**沙盒的 `127.0.0.1` 指沙盒自身，不能连接宿主机 CloudDrive。
- **跨电脑：**客户端只允许回环地址使用 HTTP，其他主机必须使用有效 HTTPS。CloudDrive Core 常见 HTTPS 端口为 19799，默认关闭，需要服务端证书，以实际设置为准。
- **待分析：**API 先建远端索引，为减少带宽，不会自动分析全部网盘视频。可切换列表按需看截图、读取时长或打开少量视频；预览仍需可访问的挂载路径、时间和流量。
- **失败或离线：**先恢复连接再重扫，不要把暂时离线当成视频已删除。

已在本机隔离资料库完成小型 115 目录的实际 API 导入、重复导入、播放和重启验收，不代表所有服务版本、超大目录或跨设备 HTTPS 均已实测。[详细配置与边界](../clouddrive2-acceleration.md)。

## 5. 浏览、搜索和整理

| 页面或入口 | 用途 |
| --- | --- |
| 资产中心 | 数量、容量、来源、最近扫描与异常提醒 |
| 视频浏览 | 文件名搜索，按名称/大小/时长/修改时间排序，网格/列表切换 |
| 收藏 / 最近播放 | 找回收藏和最近打开的视频 |
| 资料库目录 / 浏览目录 | 来源总览、目录树、子目录、名称或路径查找 |
| 视频数据 | 按条件查询、详情、复制路径，选中后导出 CSV |
| 异常中心 / 播放诊断 | 查看缺失或失败，按具体问题重试或诊断 |

- 左侧箭头展开目录，点击名称进入内容；注意 **包含子目录** 的范围开关，空列表不一定表示没有更深层视频。
- 网格可调整预览大小，每页数量可选 30 / 50 / 100 / 200 / 300。
- 目录手柄只调整同级显示顺序，不移动文件；各分组折叠和排序会保存。
- JPG/JPEG、PNG、WebP、GIF、BMP、AVIF 等图片可按目录浏览与打开大图，不进入视频索引或视频去重。
- 外部新增或改动文件后，在来源 **更多操作 → 重新扫描**；扫描时可用的暂停/继续也在来源菜单。

**来源菜单 → 从资料库移除** 展示索引影响，确认后移除来源记录，保留原视频；嵌套来源可能仍覆盖部分文件，以确认框说明为准。

视频的**重命名、移动、永久删除**会操作真实文件。重要视频先备份，网盘操作还依赖云端权限、网络与服务行为。

## 6. 播放和字幕

点击封面打开独立播放窗口，可以播放/暂停、拖进度、调音量、全屏、使用播放列表。最近播放与进度会保存，重开时按应用记录继续。

**设置 → 播放** 可调整默认自动播放、快进/快退秒数与播放策略。正式绿色包带内嵌兼容解码运行库，部分容器和编码会切换内嵌解码，无需另装 FFmpeg。黑屏或读取失败时先确认源路径可读，再看 [常见问题](#10-常见问题)。

字幕使用步骤：

1. 在播放器点 **找字幕**（可访问名称为“查找字幕”）。
2. 片名不准时点 **更多字幕 / 修改片名**，调整搜索词、语言或来源。
3. 核对影片版本后点 **下载并使用**。
4. 不同步时调 **时间偏移（秒） → 应用偏移**；可以选已保存字幕或关闭外挂字幕。

| 字幕来源 | 配置要求 |
| --- | --- |
| 迅雷字幕 | 默认查询，无需密钥 |
| Subtitle Cat | 可选网站，单独按需查询，无需密钥 |
| ASSRT 射手网 | 在 **设置 → 在线字幕** 配置自己的 Token |
| OpenSubtitles | 配置 API Key；下载还需要账号，额度由提供方决定 |

查询会连接第三方，可能发送文件名、关键词、语言或匹配信息；候选分数不保证实际语言、版本准确。外部播放器可在更多字幕中导出原始字幕，再手工载入。

## 7. 常用快捷键

以下为默认值；**设置 → 快捷键** 可修改可配置项，同一页面内不能重复。输入框或弹窗内行为可能不同。

| 使用位置 | 快捷键 | 功能 |
| --- | --- | --- |
| 视频浏览 | `←` / `→` | 上一页 / 下一页 |
| 主窗口 | `Ctrl+K` | 资料库目录总览 |
| 播放器 | `空格` | 播放 / 暂停 |
| 播放器 | `←` / `→` | 快退 / 快进，默认 10 秒 |
| 播放器 | `↑` / `↓` | 调音量，每次 5% |
| 播放器 | `Ctrl+←` / `Ctrl+→` | 向左 / 右旋转 90° |
| 播放器 | `Ctrl+D` | 打开永久删除确认框，不直接删除 |
| 目录排序手柄 | `Alt+↑` / `Alt+↓` | 调整同级顺序 |
| 图片大图 | `←` / `→`、`Esc` | 上一张 / 下一张、关闭 |

外部播放器使用自身快捷键。

## 8. 异常与重复文件

扫描异常先在资产中心查看结果，或到异常中心看来源和错误。接好移动硬盘、恢复共享/网盘连接后重试，不要删除整个资料库解决连接问题。

“缺失”是最近索引状态，不能单凭它证明文件可安全删除。“待分析”可能是排队或网盘按需分析；“分析失败”需要查看具体错误后重试。

重复候选清理步骤：

1. 打开 **重复文件**，检查候选与建议保留项。
2. 大小、时长相同只表示候选；需要清理时点 **验证当前页**，确认完整读取文件并计算 SHA-256。
3. 到 **后台任务** 看结果。
4. 只有完整哈希验证相同、文件身份仍有效的候选可继续删除；核对保留/删除计划，输入大写 **`DELETE`** 二次确认。

**永久删除不进 Windows 回收站，数据库不能恢复原视频。** 云端完整哈希可能读取大量数据；重要文件先备份并考虑流量、耗时。离线、取消、验证失败或文件变化时停止操作。

## 9. 备份、升级和移除程序

### 数据在哪里

| 程序身份 | 默认数据目录 |
| --- | --- |
| 正式免费分享版及同社区身份候选 | `%APPDATA%\local-video-manager-community` |
| 隔离绿色测试版 `unsigned-test-build` | `%APPDATA%\local-video-manager-unsigned-test` |
| 原日常开发环境 / 原签名身份 | `%APPDATA%\local-video-manager` |

验收时也可能指定独立目录，以实际启动方式为准。不同身份不自动合并、迁移；不要只凭窗口名称或相同版本号判断资料库相同。

### 备份

1. 正常关闭程序及相关窗口。
2. 复制整个对应应用数据目录到备份位置，保留 `library.sqlite`、设置和凭据材料；不要在数据库仍写入时只复制单个 SQLite 文件。
3. 原视频另做备份，缓存可以重建，但不能靠重建缓存恢复个人标记与原视频。
4. 备份可能包含私人路径、记录与受保护凭据，不公开上传。换电脑或 Windows 用户后可能需要重新配置凭据。

### 更新同一身份的绿色版

1. 备份并退出旧版。
2. 下载新 ZIP 与校验和，完整解压到**新文件夹**，避免混合新旧 DLL。
3. 运行新版，核对数量、收藏、来源与播放记录。
4. 更新自己的快捷方式，确认指向新版，再移除旧程序文件夹。

同一发行身份通常沿用数据，无需每次重新导入。数据库升级后要回退时，使用升级前完整备份，不直接用旧程序打开升级后的数据库。

### 移除程序

绿色 ZIP 无需运行卸载器；退出后删除自己解压出的程序文件夹即可，用户数据与源视频仍保留。需要清除个人数据时先核对并备份对应目录。程序移除、清理缓存、永久删除视频是不同操作。[免安装版说明](../portable.md)。

## 10. 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 无法启动、缺 DLL | 完整解压、保留配套文件、适用 x64；重下载并校验，不删资料库 |
| 添加后找不到视频 | 目录、后缀、扫描错误、搜索条件、目录及包含子目录范围 |
| 有封面但时长待分析 | 网盘可能按需分析；列表查看可见预览或打开少量视频，不必反复全库扫描 |
| 黑屏、无声、进度不动 | 源文件能否读、网盘是否在线或缓冲；查看播放诊断，必要时试系统默认播放器 |
| `ECONNREFUSED 127.0.0.1:19798` | 当前环境是否运行 CloudDrive、端口是否正确；沙盒回环不连宿主机 |
| HTTP 地址不允许 | 非回环地址需有效 HTTPS，检查服务端与证书 |
| API 成功但无来源 | 是否挂载、Token 有无读挂载点权限、本地映射是否在当前电脑可见 |
| Token 已配置但替换框空白 | 正常保护，留空保留；换机器/用户或凭据损坏时重新输入 |
| 换程序文件夹资料库还在 | 正常，资料库在 Windows 用户目录 |
| 两个程序看到不同资料库 | 检查发行身份、快捷方式目标、隔离目录，不直接覆盖另一份库 |
| 搜不到合适字幕 | 修改片名、年份、季集、来源、语言；检查提供方权限与额度 |

## 11. 反馈问题

到 [GitHub Issues](https://github.com/huntian0727/movie/issues) 提供：应用版本和文件名、Windows 版本、是否沙盒、本地/NAS/挂载/API 来源、复现步骤、预期结果及脱敏错误。播放问题尽量附容器、视频/音频编码、分辨率。

必要时在 **设置 → 诊断与日志** 先预览再导出，审阅后分享。不公开 Token、密码、整份数据库、私人视频或未经处理的目录清单。安全漏洞按 [私人报告说明](../../SECURITY.md)反馈。
