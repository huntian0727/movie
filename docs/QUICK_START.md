# 映匣快速开始（当前软件名：拉面影视）

> **发布状态：** 目前没有获准公开下载的 Windows 安装包。本教程用于日后正式发布的版本；现有 `unsigned-test-build` 只供隔离测试，不能给普通用户升级使用。

## 适用系统与安装

目标平台为 Windows 11 x64。正式安装包发布时，用户不需要安装 Node.js、npm、Git、Python 或单独安装 FFmpeg；但这不代表所有视频都能直接在内嵌播放器播放。发布时请从 [官方 Releases](https://github.com/huntian0727/movie/releases) 下载与版本相同的校验清单，按 [安装与 SHA-256 核对教程](windows-installation.md) 确认来源和哈希。不要为安装而关闭 Windows 安全功能。

## 首次建立资料库

1. 打开应用，进入“资料库目录”或视频浏览区，按界面入口添加**本地磁盘文件夹**，例如 `D:\Movies`。
2. NAS/SMB 目录可在 Windows 已取得访问权限后按路径添加，例如 `\\NAS\Video`；首次使用先选一个小目录，确认联网与权限正常。
3. 触发扫描，等待来源目录的状态完成。视频索引在本机 SQLite 中保存；元数据读取和封面生成可能随后继续进行。
4. 在视频浏览、资产中心、目录树或搜索中找到视频；点击播放并确认图像和声音。若内嵌播放不支持某个格式，可尝试系统播放器。**NativeHost 不等于已内置完整 libmpv。**
5. 退出后再打开应用，确认来源目录、索引和缓存仍可正常使用。

## 数据位置和外部连接

- 源视频通常留在原目录，建立索引或清理缓存不需要搬动视频文件。正式身份目前使用 `%APPDATA%\local-video-manager` 保存 `library.sqlite`、设置和预览缓存；测试身份使用不同的数据目录。
- 卸载当前安全安装器不会主动清理源视频和独立用户数据，但**应用内的永久删除是真删除**。把数据库备份和源视频备份分开保存。
- CloudDrive2 是可选功能；连接时会访问用户配置的服务。在线字幕搜索/下载也可能发送搜索关键词、文件名或语言给第三方。不要把“本地优先”等同于“绝对零网络请求”。

## 避免误删

“大小、时长相同”只能产生重复**候选**，不能证明文件内容一致。当前候选版要求完整 SHA-256 核对并再次输入大写 `DELETE` 才允许重复清理的永久删除。即便如此，仍应先备份重要视频。不要拿真实资料库测试扫描异常清理和重复删除。

## 出现问题

先记录 Windows 版本、应用版本及经过脱敏的错误信息，在 [GitHub Issues](https://github.com/huntian0727/movie/issues) 反馈普通 Bug；Token、个人视频、SQLite 数据库、真实目录清单和可利用的安全漏洞不要提交到公开 Issue，按 [私人安全报告指南](../SECURITY.md) 处理。

已知限制及发布状态参阅 [README](../README.md) 和 [发布检查清单](RELEASE_CHECKLIST.md)。
