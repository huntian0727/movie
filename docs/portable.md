# Windows x64 绿色免安装版

截至 2026-10-21，当前最新公开版为 **[0.1.15](https://github.com/huntian0727/movie/releases/tag/v0.1.15)**，程序文件为 **Movie-0.1.15-Windows-x64-Portable.zip**。完整解压，运行“拉面影视-免费分享版.exe”；无需安装 Node.js、FFmpeg 或手工提供播放器 DLL。[0.1.15 完整使用教程](user-guide/0.1.15.md)。

**0.1.16 仍为私有候选，尚未公开发布。** 不要将内部 QA 安装器或候选教程当成正式下载。

“免安装”描述程序使用方式；资料库、设置与缓存仍在 Windows 用户数据目录，没有承诺把个人数据全部放在程序旁的跨机器便携模式。

## 身份与数据

| 发行身份 | 默认数据目录 | 使用关系 |
| --- | --- | --- |
| 正式免费分享版 / 同社区身份候选 | `%APPDATA%\local-video-manager-community` | 同身份通常沿用资料库；社区候选和正式版测试时仍应主动隔离 |
| 隔离 unsigned-test-build | `%APPDATA%\local-video-manager-unsigned-test` | 测试资料库，与免费分享版和原日常版分开 |
| 原开发环境 / 原签名身份 | `%APPDATA%\local-video-manager` | 保留原资料库位置 |

验收启动可指定独立目录，以实际启动方式为准。程序发行身份与数据目录必须匹配；缺失或错误的构建身份会在打开资料库前拒绝启动。不同身份不自动合并、迁移资料库或凭据，不要把隔离测试包改名当正式包。

## 安装、移动与更新

1. 核对同版本校验和，把 ZIP 完整解压到自己的文件夹；保留 resources 与所有配套 DLL，不直接从压缩软件启动。
2. 双击 EXE，可自行创建桌面快捷方式。ZIP 不自动建立安装注册项、快捷方式或文件关联。
3. 更新前退出并备份整个对应数据目录，原视频单独备份。
4. 新版解压到新文件夹，确认数量、收藏、来源、历史正常，再修改快捷方式、移除旧程序目录。避免覆盖解压混用 DLL。

程序路径移动不会改变同身份的资料库位置。视频索引使用源文件路径；盘符或视频位置改变后，需要按新路径重新添加/扫描。换电脑、换 Windows 用户后，安全存储凭据可能需要重新输入。数据库升级后回退应使用升级前备份，不直接让旧程序打开升级后的库。

## 不再使用

退出后移除自己解压出的程序文件夹即可，没有 ZIP 卸载器步骤。用户数据与源视频仍保留；要删除个人数据时先核对并备份对应目录。应用内永久删除与移除程序不同，会真实删除源文件。

## 开发者

固定 Node/npm 后使用 `npm run dist:zip`，输出到对应发行身份目录。Electron 离线包使用 `MOVIE_ELECTRON_DIST_ZIP` 且仍校验固定 SHA-256。当前源码运行库路线及成品验收按 [SOURCE_COMMUNITY_RELEASE](SOURCE_COMMUNITY_RELEASE.md)，构建不会自动批准公开发行。

日常开发 → 候选测试 → 正式发布及教程同步见 [维护约定](DEVELOPMENT_AND_RELEASE.md)。历史静态 Lite 与安装器方案不代表当前 ZIP 状态，安装器需独立验收。
