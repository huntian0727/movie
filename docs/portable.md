# Windows x64 ZIP 免安装版

ZIP 与安装器使用同一套应用和原生播放器。完整解压到自己的普通文件夹，再双击包内的 EXE。不要直接从压缩软件中运行 EXE；不要单独移动 EXE，`resources` 及其他配套文件必须一起保留。无需另装 Node.js、FFmpeg 或手动提供播放 DLL。

当前仅提供隔离 `unsigned-test-build` 本机验收候选。公开发行条件与安装器一致，第三方来源、许可和干净 Windows 验收未批准之前，不视为正式免费分享版。

## 数据与升级

这是免安装程序包，资料库、设置和缓存仍保存在 Windows 用户数据目录；当前 QA 身份使用 `%APPDATA%/local-video-manager-unsigned-test`，不会读取正式用户库。用户视频保留在添加的源目录，本包不包含个人资料库和视频。

| 发行身份 | 资料库目录 | 升级行为 |
| --- | --- | --- |
| 隔离测试版 | `%APPDATA%/local-video-manager-unsigned-test` | 同身份新版继续使用测试库 |
| 免费分享版（发行条件仍待批准） | `%APPDATA%/local-video-manager-community` | 同身份新版保留资料库；首次使用不会自动读取旧版或测试库 |
| 原签名版 / 开发环境 | `%APPDATA%/local-video-manager` | 保留已有库和设置位置 |

发行身份、应用 ID 和资料库目录必须一致；缺失或不匹配的包在打开资料库前拒绝启动。不同身份之间不自动迁移资料库或凭据。

更新时先退出程序，将新版完整解压到新文件夹，再运行同一发行身份的新版；修改自己创建的快捷方式目标即可。删除旧程序文件夹不会清除用户数据。无需运行卸载器，不自动创建桌面快捷方式、文件关联或安装注册项。

程序路径可移动，但当前视频索引使用源文件绝对路径；将媒体搬到另一台电脑或改变盘符，需要重新添加/扫描对应视频目录。此版没有承诺将资料库、设置及凭据全部放在程序旁边的跨机器便携模式。

## 开发者构建

使用项目固定 Node/npm 后执行 `npm run dist:zip`。播放器 DLL 固定来源自动获取并校验；离线时可提供 `MOVIE_LIBMPV_DLL`，仍须匹配锁定哈希。Electron 离线包仍使用既有 `MOVIE_ELECTRON_DIST_ZIP`。输出位于对应发行身份目录，名字以 `-Portable.zip` 结尾。ZIP 构建不绕过任何正式发行审批。
