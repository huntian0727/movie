# 0.1.15 正式绿色版发布决定

日期：2026-10-13，Asia/Shanghai。

维护者在本次对话明确要求：“不考虑windows版本，我这个版本也非常稳定，就使用这个版本进行正式版的测试和发布”。该最新指令替代此前必须等待稳定版 Windows 的验收条件，并授权完成当前环境测试后公开正式绿色版，不再重复请求发布授权。

发行范围仅为 0.1.15 Windows x64 未签名社区绿色 ZIP。应用和资料库身份沿用公开 beta；不授权 NSIS 安装器、签名发行或旧生产身份升级。操作系统实际记录为 Windows 11 Enterprise Insider Preview 26100.9606，默认沙盒账号；不把它写成非预览系统或标准用户认证。正式版是项目发行渠道，不是对全部 Windows 环境的兼容性认证。

复用已有扫描、封面、暂停、跳转、重启保存、移动/移除绿色程序保留数据及五种音视频组合验收；仅在 39 个原生 PE 与已听测包完全一致时复用声音确认。最终 0.1.15 ZIP 仍需对应 commit 的 CI、安全检查、源码配对、解压 smoke、许可证逐字节核对及当前沙盒实际启动和播放。任何失败都不得公开。

未覆盖的 4K/HDR、长时间压力、普通标准用户、NSIS、SmartScreen 首次下载、签名升级等继续如实披露，不再将操作系统版本作为本次发行阻塞。既有第三方许可审批、固定对应源码与 DLL 替换权利保持不变。
