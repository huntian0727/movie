# 0.1.17 正式绿色版发布决定

日期：2026-10-26（Asia/Shanghai）。

## 授权范围

维护者明确要求将当前完成阶段正式发布到 GitHub，并遵循项目既有《极简绿色 ZIP 发版 SOP》。范围仅限 **v0.1.17 / 界面 v1.43 / Windows x64 未签名免安装绿色 ZIP**。不发布 NSIS 安装器、不进行代码签名、不启用旧生产身份升级。对应 GitHub Release Draft ID：423835020。

本记录不等于最终发行批准。只有正式发布提交的 Windows CI、安全审计、固定输入验证、源码配对、绿色 ZIP 构建/解压/启动 smoke、版本身份和全部附件哈希均通过后，才可将草稿公开为 Latest；任何门禁失败都必须保持 Draft。

## 原生组件

- 复用固定的第三方 FFmpeg/MPV 运行库和对应源码输入，不重编第三方媒体栈。
- 本版只更新项目自有 MIT NativeHost，明确传递键盘按下/释放阶段，修复长按临时快进释放行为。NativeHost.cs SHA-256：d400593cb9afbc305de6f651d3d3564d5e9d75544a995e890cb6357998779069；确定性 NativeHost.exe SHA-256：61aa3328dfd98ec29fd75beb88e5630fec2769670f41f930da18cf8166446b07。
- 38 个第三方 PE 位置与字节保持原批准记录；NativeHost 为唯一更新的项目自有 PE。对应源码包必须包含当前源码、固定编译工具/引用信息、第三方源码输入和许可证材料。

## 验收边界

- 本次目标是 Windows x64 未签名绿色 ZIP；稳定版 Windows、标准用户权限、4K/HDR、长时间压力和真实 CloudDrive/115 永久删除均不在已声明覆盖范围内。
- 未签名程序可能显示 Windows 来源/安全提示；用户应核对发布页 SHA-256，不应关闭系统防护绕过提示。
- 真实资料库只做既有备份和只读核验，不用于破坏性测试；不得把未知删除结果自动重试。
