# 0.1.16 正式绿色版发布决定

日期：2026-10-22，Asia/Shanghai。

维护者已明确授权尽快发布当前 v0.1.16 / 界面 v1.6。按维护者指定的最短路线，本次只发布 Windows x64 未签名社区绿色 ZIP；不发布 NSIS 安装器、不做代码签名、不启用旧生产身份升级。该授权不代表对未测试的 Windows 版本作兼容性承诺。

## 原生组件处理

- 复用 v0.1.15 已批准的固定第三方 FFmpeg/MPV 运行库和对应源码输入，两个 runtime lock 的字节与既有批准记录一致，不重新构建第三方媒体栈。
- 本次仅因播放器倍速支持重新构建项目自有 MIT NativeHost.exe。当前源码 SHA-256 为 c175e5b97799d9157e71568eac74924c51080a6c85745e90549979ad28a18fb4，确定性构建输出 SHA-256 为 d2d3b8065aad06f2409d854e33fe3769dd04e959487fcf454976993504298ace。
- 对外说明 38 个第三方运行库 PE 位置与既有批准字节相同，NativeHost 为新构建；不声称 39 个 PE 全部不变。

## 本次验收范围

当前应用提交的 Windows CI 与安全检查已通过。发布工作流还必须执行当前源码/许可证绑定检查、针对性播放和清理安全测试、绿色 ZIP 构建、解压校验、打包启动 smoke、哈希和版本身份核验；任一失败都不公开。

为加快交付，本次不重复 v0.1.15 已完成的整套 Sandbox GUI 编解码体验测试。旧版测试只作为历史兼容性证据，不冒充 v0.1.16 的人工验收。v0.1.16 的验收范围明确限制为：当前提交的自动化验证、固定第三方运行库复用核验、NativeHost 确定性构建和最终成品 smoke。Windows 11 Insider Preview 之外的稳定系统覆盖、标准用户权限、4K/HDR、长时间压力测试和真实网盘永久删除回归均不在本次声明范围内。

## 发布资产

同一 GitHub Release 必须提供程序 ZIP、精确应用源码、对应原生源码材料、SOURCE-PAIR.json、SHA-256 清单、构建元数据和最终验证记录。未签名程序由用户按自己的风险判断运行；不发布未经本次构建和验证的候选 ZIP。
