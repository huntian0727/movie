# 视频详情弹窗设计

- 日期：2026-07-12
- 主题：播放器页增加视频详情按钮与详情弹窗
- 状态：已确认，可进入实现

## 背景

当前播放器页已经支持播放、快进快退、收藏、上一部下一部、音量和全屏等操作，但缺少一个轻量入口来查看视频的详细信息。用户在播放过程中，经常会想确认文件路径、修改日期、文件大小、格式、分辨率等属性。如果直接切换到独立详情页，会打断播放上下文；如果把信息硬塞进播放器顶栏，又会让主界面过于拥挤。

因此，这次设计选择在播放器页增加一个“详情”按钮，点击后打开居中的详情弹窗，用于只读展示当前视频的详细属性。

## 设计目标

1. 在不离开播放器页的前提下查看当前视频的详细信息。
2. 不影响当前播放状态，不引入路由切换。
3. 第一版尽量复用现有 `VideoRecord` 数据，不新增 IPC、数据库字段和扫描流程。
4. 保持信息清晰、易读，优先满足“快速核对视频属性”的场景。

## 交互方案

详情入口放在播放器顶部右侧操作区，与收藏按钮同区域展示，但视觉权重低于播放控制区。点击“详情”按钮后，打开一个居中的模态弹窗。弹窗打开时，播放器留在原页并保持当前状态，不自动暂停，不切换页面。

弹窗支持以下关闭方式：

- 点击右上角关闭按钮
- 点击遮罩区域关闭
- 按 `Esc` 关闭

弹窗底部只保留轻量操作：

- `复制路径`
- `关闭`

第一版不加入“打开所在目录”“重新生成封面”“编辑标签”等扩展操作，避免把详情弹窗做成复杂的管理中心。

## 信息结构

弹窗内容按“先回答最常见问题，再展示系统状态”的顺序组织，分为三组：

### 1. 基础信息

- 文件名
- 格式
- 时长
- 分辨率
- 文件大小

这部分帮助用户快速确认“我正在看的到底是哪一个视频文件”。

### 2. 文件信息

- 完整文件路径
- 所在目录
- 修改日期
- 导入日期

其中完整路径单独占一行，并提供复制入口。路径是排查问题和手动定位文件时最常用的信息，优先级高于内部状态。

### 3. 系统状态

- 是否收藏
- 元数据状态
- 封面状态
- 时间轴预览状态
- 是否缺失

这组信息主要面向排查和维护场景，例如用户想知道为什么没有封面、为什么预览帧没生成。

## 字段范围

第一版直接使用当前 `VideoRecord` 可用字段：

- `filename`
- `path`
- `directory`
- `extension`
- `format`
- `sizeBytes`
- `durationMs`
- `width`
- `height`
- `modifiedAt`
- `importedAt`
- `isFavorite`
- `isMissing`
- `metadataStatus`
- `thumbnailStatus`
- `timelinePreviewStatus`

这次不做“创建日期”。当前数据模型里没有 `createdAt` 字段，若第一版强行加入，会牵涉主进程扫描、类型定义、数据库与回填逻辑，超出本次最小可上线范围。创建日期可作为后续增强项追加。

## 布局建议

弹窗宽度使用中等尺寸，内容区采用“标签 + 值”的双列信息布局，完整路径单独占满一行。对于值较长的字段：

- 路径默认最多显示两行
- 超出部分截断显示
- 通过 `title` 或复制操作保证完整信息可取

字段缺失时使用统一降级文案：

- `未识别`
- `暂无`

不直接显示 `null`、`undefined` 或空白。

## 实现边界

第一版实现收敛在 renderer 层，主要改动如下：

- `src/renderer/components/PlayerPage.tsx`
  - 增加“详情”按钮
  - 管理弹窗开关状态
- 新增 `src/renderer/components/VideoDetailsDialog.tsx`
  - 负责渲染详情弹窗内容
- 视情况补充格式化辅助函数
  - 日期格式化
  - 状态文案格式化

明确不在第一版内实现：

- 创建日期
- 打开所在目录
- 修改元数据
- 重新生成封面或预览
- 显示更底层的 codec/bitrate 等技术细节

## 异常处理

详情弹窗是只读能力，策略应以“稳定展示”为先：

- 字段缺失时展示降级文案，不报错
- 日期格式异常时回退展示原始字符串
- 路径复制失败时展示轻量错误提示
- 打开详情弹窗不应导致播放器卸载或重建

## 测试建议

建议补以下测试点：

1. 点击“详情”按钮可以打开弹窗
2. 点击关闭按钮、遮罩、按 `Esc` 都能关闭弹窗
3. 路径复制按钮能触发复制逻辑
4. 字段缺失时依然能稳定渲染
5. 打开弹窗后播放器本身不被卸载，播放状态不被重置

## 推荐结论

对当前项目来说，最合适的第一版方案是：

- 在播放器页顶部增加“详情”按钮
- 使用居中模态弹窗展示详细信息
- 先基于现有 `VideoRecord` 字段落地
- 以“查看信息”为目标，不扩展为管理型面板

这能在最小改动下补齐播放场景中的信息查看能力，风险低、上线快，也为后续追加创建日期和更多文件操作留出了清晰扩展点。
