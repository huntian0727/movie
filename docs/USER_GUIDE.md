## 1. 下载和启动

当前公开版请打开 [0.1.15 Release 下载页](https://github.com/huntian0727/movie/releases/tag/v0.1.15)，下载 **`Movie-0.1.15-Windows-x64-Portable.zip`** 和 **`SHA256SUMS.txt`**。0.1.16 候选尚未公开发布。

带 `Application-Sources`、`Corresponding-Sources` 或 GitHub 自动生成的 `Source code` 是源码材料，普通使用无需编译它们。`beta` 是公开测试版，`unsigned-test-build` 是隔离测试身份；不同身份不能当成同一程序覆盖升级。

1. 按 [文件校验说明](windows-installation.md)核对 ZIP。
2. 完整解压到自己的普通文件夹，例如 `D:\Apps\Movie-0.1.16`。
3. 双击 **`拉面影视-免费分享版.exe`**；可自行为它创建桌面快捷方式。

保留 `resources`、DLL 等配套文件，不要只拿走 EXE，也不要直接在压缩软件内运行。无需另装 Node.js、npm、FFmpeg 或手工寻找播放器 DLL。CloudDrive 属于网盘场景可选的独立软件，本地视频不需要它。

当前发布目标为 Windows 11 x64，实际验收使用 Windows 11 Insider Preview 沙盒。安装器、Windows ARM、其他系统和全部硬件组合未作统一兼容保证。包未签名；核实来源与哈希，出现安全拦截时反馈维护者，不需要关闭系统防护。

### 本地开发版新增：本页自动分析（2026-10-20，尚未作为公开版本发布）

视频浏览的工具栏下方新增 **开启本页自动分析**，默认关闭。开启后仅对当前页面状态为「待分析」且文件大小大于 0、未标记缺失的视频，依次请求获取时长等元数据。本页已就绪、待分析及无法自动处理数量显示在按钮旁。翻页、搜索或切换目录时，上一页专属未启动请求自动取消，新页加载完成后继续；关闭开关或离开浏览页面也会停止专属请求。正在执行的读取可能有界完成并保存结果。

云盘分析优先尝试轻量时长，取得时长就可能结束，因此「分辨率未知」并不表示分析失败。分析失败的记录需要在 **异常中心 → 分析失败** 处理；仅仅浏览视频不会启动本功能，也不会更改全库 CloudDrive 的默认暂缓策略。

## 2. 第一次添加视频

先用一个含几段视频的小文件夹熟悉操作：

1. 点击右上角 **添加资料库 → 添加本地或挂载目录**。
2. 在 Windows 文件夹选择窗口中选择目录，例如 `D:\Videos\示例`。
3. 默认递归扫描子文件夹；**设置 → 资料库 → 默认递归扫描** 可调整以后添加目录的默认行为。
4. 等待 **资产中心 → 扫描状态** 或来源状态完成。扫描、元数据分析和预览生成是不同阶段，缩略图与时长可能稍后出现。
5. 左侧选择 **视频浏览**，点击封面播放；试一下收藏和最近播放。
6. 退出后重开，确认目录、索引和个人记录保留。

添加目录建立本机索引，原视频保留原位置，不会把整个视频文件夹复制到程序目录。可识别后缀为 `MP4、MKV、AVI、MOV、FLV、WEBM、WMV、M4V、TS`；识别后缀不等于所有编码组合都能播放。

## 3. 各种目录添加方式怎么选

| 视频在哪里 | 添加方式 | 需要准备 | 区别 |
| --- | --- | --- | --- |
| 本机、移动硬盘 | 添加本地或挂载目录 | Windows 可访问目录 | 普通文件夹扫描，使用直接 |
| NAS / SMB | 添加本地或挂载目录，选择盘符或 `\\NAS\Video` | 先在 Windows 确认连接与权限 | 索引在本机，扫描和播放依赖网络与共享权限 |
| 已挂载网盘 | 添加本地或挂载目录，例如 `F:\视频` | CloudDrive 等已登录、绑定并挂载 | 走 Windows 目录入口；配置了匹配的 CloudDrive API 时，扫描器可利用 API 加速 |
| CloudDrive API 目录 | 通过 CloudDrive API 添加 | 地址、Token、可访问的挂载路径 | 逐层浏览远端目录、保存远端身份；目录枚举避免逐视频读取本地属性 |

两种 CloudDrive 入口的重点是如何选目录、是否保存远端身份及扫描条件。API 不会把所有视频复制进程序，也不代表不用挂载就能播放。预览、媒体分析和播放仍可能读取内容并产生网盘流量。

普通添加窗口以**目录**为单位；目前不提供把单个视频、ZIP、网盘分享链接或任意播放 URL 当成资料库导入的入口。目录树拖动调整显示顺序，不是拖入视频文件导入。

先选择真正的视频目录，确认结果后再扩大范围，避免一开始添加整个系统盘或全部网盘根目录。

## 4. 115 与 CloudDrive API

### 先准备网盘挂载

1. 在自己的电脑安装并运行 CloudDrive，按提示登录、绑定 115。
2. 完成挂载，确认 Windows 资源管理器能打开测试视频目录，例如 `F:\测试视频`。
3. 先选少量文件测试。CloudDrive 的服务、会员、流量或提供方限制由对应软件与网盘决定。

Movie 不内置 115 登录，也不会替你申请 Token。[CloudDrive 官方帮助](https://www.clouddrive2.com/help.html)提供服务安装、绑定、挂载和 API 说明。

### 配置连接并添加

**0.1.16 候选版计划提供：**右上角 **设置 → CloudDrive API**。该候选尚未公开发布。


**0.1.16 候选范围：**也可从 **添加资料库 → 通过 CloudDrive API 添加 → 配置 API** 直接定位设置区域；返回会重新读取来源。此项是否随候选正式发布，以最终获准的包为准。


| 配置项 | 填写方法 |
| --- | --- |
| API 地址 | Movie 与 CloudDrive Core 同机时常见为 `http://127.0.0.1:19798`，以实际服务地址为准 |
| API Token | 从 CloudDrive API 令牌管理取得，只填程序，不发到聊天或公开 Issue |
| 请求超时 | 默认 `20000` 毫秒，先保留默认 |
| 手动挂载映射 | 通常留空，自动读取挂载点；自动路径不正确时才填写 |

1. 填写后点击 **保存并测试连接**。
2. 成功后返回，点击 **添加资料库 → 通过 CloudDrive API 添加**。
3. 选择挂载来源，逐层打开目标目录，核对远端与本地路径。
4. 点击 **添加并扫描此目录**，查看扫描结果。

Token 已配置时，替换框留空会保留现有 Token；输入新值再保存才会替换。保存的明文不会重新显示。

### 容易混淆的情况

- **本机与沙盒：**沙盒的 `127.0.0.1` 指沙盒自身，不能连接宿主机 CloudDrive。
- **跨电脑：**客户端只允许回环地址使用 HTTP，其他主机必须使用有效 HTTPS。CloudDrive Core 常见 HTTPS 端口为 19799，默认关闭，需要服务端证书，以实际设置为准。
- **待分析：**API 先建远端索引，为减少带宽，不会自动分析全部网盘视频。可切换列表按需看截图、读取时长或打开少量视频；预览仍需可访问的挂载路径、时间和流量。
- **失败或离线：**先恢复连接再重扫，不要把暂时离线当成视频已删除。

已在本机隔离资料库完成小型 115 目录的实际 API 导入、重复导入、播放和重启验收，不代表所有服务版本、超大目录或跨设备 HTTPS 均已实测。[详细配置与边界](clouddrive2-acceleration.md)。

## 5. 浏览、搜索和整理

| 页面或入口 | 用途 |
| --- | --- |
| 资产中心 | 数量、容量、来源、最近扫描与异常提醒 |
| 视频浏览 | 文件名搜索，按名称/大小/时长/修改时间排序，网格/列表切换 |
| 收藏 / 最近播放 | 找回收藏和最近打开的视频 |
| 资料库目录 / 浏览目录 | 来源总览、目录树、子目录、名称或路径查找 |
| 视频数据 | 按条件查询、详情、复制路径，选中后导出 CSV |
| 异常中心 / 播放诊断 | 查看缺失或失败，按具体问题重试或诊断 |

- 左侧箭头展开目录，点击名称进入内容；注意 **包含子目录** 的范围开关，空列表不一定表示没有更深层视频。
- 网格可调整预览大小，每页数量可选 30 / 50 / 100 / 200 / 300。
- 目录手柄只调整同级显示顺序，不移动文件；各分组折叠和排序会保存。
- JPG/JPEG、PNG、WebP、GIF、BMP、AVIF 等图片可按目录浏览与打开大图，不进入视频索引或视频去重。
- 外部新增或改动文件后，在来源 **更多操作 → 重新扫描**；扫描时可用的暂停/继续也在来源菜单。

**来源菜单 → 从资料库移除** 展示索引影响，确认后移除来源记录，保留原视频；嵌套来源可能仍覆盖部分文件，以确认框说明为准。

视频的**重命名、移动、永久删除**会操作真实文件。重要视频先备份，网盘操作还依赖云端权限、网络与服务行为。

## 6. 播放和字幕

点击封面打开独立播放窗口，可以播放/暂停、拖进度、调音量、全屏、使用播放列表。最近播放与进度会保存，重开时按应用记录继续。若播放器窗口已经打开，再从主窗口点击另一个视频，播放器应切换到新选择的视频，而不是只把旧窗口带到前台。

**维护者本地开发版（尚未公开发布）的修复：**已修复上述切换问题；当前 GitHub 正式版 0.1.15 及尚未公开的 0.1.16 候选包不包含此修复。

**设置 → 播放** 可调整默认自动播放、快进/快退秒数与播放策略。正式绿色包带内嵌兼容解码运行库，部分容器和编码会切换内嵌解码，无需另装 FFmpeg。黑屏或读取失败时先确认源路径可读，再看 [常见问题](#10-常见问题)。

字幕使用步骤：

1. 在播放器点 **找字幕**（可访问名称为“查找字幕”）。
2. 片名不准时点 **更多字幕 / 修改片名**，调整搜索词、语言或来源。
3. 核对影片版本后点 **下载并使用**。
4. 不同步时调 **时间偏移（秒） → 应用偏移**；可以选已保存字幕或关闭外挂字幕。

| 字幕来源 | 配置要求 |
| --- | --- |
| 迅雷字幕 | 默认查询，无需密钥 |
| Subtitle Cat | 可选网站，单独按需查询，无需密钥 |
| ASSRT 射手网 | 在 **设置 → 在线字幕** 配置自己的 Token |
| OpenSubtitles | 配置 API Key；下载还需要账号，额度由提供方决定 |

查询会连接第三方，可能发送文件名、关键词、语言或匹配信息；候选分数不保证实际语言、版本准确。外部播放器可在更多字幕中导出原始字幕，再手工载入。

## 8. 异常与重复文件

扫描异常先在资产中心查看结果，或到异常中心看来源和错误。接好移动硬盘、恢复共享/网盘连接后重试，不要删除整个资料库解决连接问题。

**异常中心总览的统计口径（0.1.16）：**“需要核查的记录”表示待核查的记录条数，**不等于独立的故障原因数量**。同一网盘或资料库来源有大量记录时，优先查看下方“来源级问题”，不要逐条删除。来源统计综合已记录的扫描错误与最近可访问性检查；两者可能重叠且目前无法精确求并集，故按保守口径显示“至少”多少个来源。最近可访问性显示正常或未知，也不代表此前记录的扫描错误已全部消失。先解决连接、路径、权限问题，再复查明细。

**问题与后台任务分离（0.1.16）：** 侧栏“需要处理”只统计文件缺失、扫描失败与元数据分析失败等需核查记录（同一记录可能跨类别，汇总时会去重）；**正常待分析或 CloudDrive 暂缓分析不计入异常数字**。侧栏另有“后台任务”，其中的任务不是故障，不必全部重新分析。问题中心顶栏分别展示“问题总览 / 扫描失败 / 文件缺失 / 分析失败”，最右侧独立为“后台元数据任务”。点击“分析失败”默认只看失败；点击“后台任务”默认只看“暂缓分析”，也可主动改为“待自动分析”或“全部状态（含失败）”。后台暂缓的常见原因是避免海量远程读取，无需处理；需要技术信息时才手动优先分析，可能产生网盘流量。真正失败时先看网络、权限、文件是否存在与解析错误，确认原因后再试。0B 文件先重新读取大小。**不建议通过批量清理数据库记录来让异常数字变成 0。**

**异常中心页面布局（0.1.16）：** 页面上方的问题分类和单独的“后台元数据任务”可以相互切换。总览页没有独立工具栏，因此标签栏应直接位于全局菜单下方，**不能覆盖“异常中心”标题、说明或刷新统计按钮**；其他三个明细页仍保留独立工具栏。若标题被遮挡，请检查是否仍在运行 0.1.15 及更早版本。

扫描异常页面底部的 **处理历史** 保留最近 50 条批量操作记录，包含操作类型、处理范围、成功/跳过/失败数量与失败摘要。取消任务会保留已处理计数；程序重启后仍未完成的任务会标记为“意外中断”，未完成项不会自动重试。单项清理和批量操作都需要确认；永久删除只允许处理经过独立复核确认损坏的视频。

“缺失”是最近索引状态，不能单凭它证明文件可安全删除。“待分析”可能是排队或网盘按需分析；“分析失败”需要查看具体错误后重试。

重复候选清理步骤（本地开发版）：

**优先保留目录同时控制浏览筛选**：在任意重复项文件右侧点击“优先保留此目录”，会立即只展示此目录及其所有子目录**所涉及**的重复组，自动回到第 1 页，并优先推荐保留该目录树中的文件。为方便判断该删除哪一份，组内其他目录的对应副本仍会显示，但无关重复组会隐藏。目录设置会保存并在下次进入时恢复；点击“显示全部”可临时解除目录范围筛选，而不删除偏好设置。若保存或查询失败，界面会提示原因，不会把全部重复组冒充为筛选结果。

1. 打开 **重复文件**，核对候选和计划保留项。判重只使用精确文件大小与四舍五入到整秒的时长。
2. **单项**：点击文件行末垃圾桶，检查文件名及路径，点“确认删除此文件”。
3. **当前页批量**：先为每组设定保留文件，点击“清理当前页”，核对当前页组数、删除文件数和预计释放空间后一次确认。
4. 软件会自动复查同组关系、大小、时长、路径、修改时间与文件身份。预检查发现状态变化会阻止删除，逐项执行时的失败会显示明细；不会读取全部视频计算哈希。

**后台清理的列表行为（维护者本地界面版 v1.2，未公开发布）**：单文件或「清理当前页」经后台正式受理后，当前重复项列表立即**暂时隐藏已入队的待删项**，同组保留文件不被隐藏或删除。此时顶部状态栏仍显示任务进度；列表数字若标注「含排队项」是后端原始统计，不能误认为剩余待操作数量。若一页内已经覆盖所选目录中的全部重复组，入队成功后自动返回「显示全部」，**仅撤销浏览筛选**，不会删除已保存的「优先保留此目录」偏好；若还有后续页，则继续停留在当前筛选范围，整页已入队时可以直接查看下一页。任务完成后列表重新读取数据库，明确失败、未提交和待核实项目重新呈现；未成功提交时不会隐藏或退出筛选。退出程序不会继续后台任务，重启后不自动重试未确认的删除操作。

**后台清理模式（本地开发版）**：确认单文件或“清理当前页”后，程序立即返回，不再等待删除完成。任务在 Electron 主进程中按最多 30 项一批继续进行，你可以浏览资料库、切换目录、使用播放器。各个页面顶部都有折叠的“重复文件后台清理”进度栏，展开可查看成功、失败、回收站与结果未知项。后台清理期间不能再次发起另一批重复清理，以免重复操作。**任务仍需保持应用程序运行；退出软件不会在关机后继续执行。** 程序意外关闭后保留最后检查点，重新启动将未确认的待处理结果标记为“中断／需要核实”，不会自动继续或自动重试；应先核对云盘状态。

本地优化版会合并 CloudDrive 同批次的远端状态核对，最多同时处理 3 个已核对的删除请求，减少等待时间；**不计算视频内容哈希，也不会因为提速绕开保留文件检查**。实际速度取决于 CloudDrive 远端接口响应；批量任务当前以整批完成后汇总数量，处理期间如遇网盘请求断连会等待已提交项返回并停止后续任务。请不要在进行批量清理时强制退出程序。

**重复文件的快捷删除接口与普通视频删除不同。** 主进程会按已选择的保留/待删文件分组验证，检查受管来源路径及文件版本后再逐项删除。若文件已变化、挂载盘不可安全访问或后台任务占用，系统返回明确失败数量与原因，不会把已被安全规则提前拦截的删除误报为通信结果未知；真正的通信断连仍视为未知，须手动核对，不可自动重试。普通资料库的永久删除入口依旧不允许绕开重复组保护。云盘虚拟挂载可能因重解析/链接或文件系统能力被安全拒绝，不应通过关闭保护规则强制执行。

页面默认保留单文件垃圾桶和“清理当前页”；**检查缺失、快速绑定旧资料库、后台核对任务**统一在“高级核对与维护工具”中展开。需要独立任务核对时点击其中的 **验证当前页**，待后台核对结束后检查并输入大写 **`DELETE`** 二次确认。该高级流程不是常用手动清理的必经步骤。

批量清理确认后可在弹窗查看已确认处理数量、成功数和失败数。结果明细展示明确失败的文件及原因；点击“仅重新核对失败项”，系统会再次展示确认弹窗、重新安全预检，仅重试**已明确失败**的文件。**若发生网盘通信中断，正在执行的那批文件可能部分已删除：系统会明确提示“结果未知”，并保留前序成功结果，绝不把未知当成失败自动重试。** 应先刷新列表、核对网盘真实状态，再决定后续操作。

**重要：大小和时长相同是低带宽判定规则，不保证视频内容逐字节相同；不同内容但大小/时长相同的文件可能被当作重复项。** 永久删除不进 Windows 回收站，数据库不能恢复原视频。请认真检查候选及保留项；文件状态、路径或身份变化时，程序会停止删除。

## 9. 备份、升级和移除程序

### 数据在哪里

| 程序身份 | 默认数据目录 |
| --- | --- |
| 正式免费分享版及同社区身份候选 | `%APPDATA%\local-video-manager-community` |
| 隔离绿色测试版 `unsigned-test-build` | `%APPDATA%\local-video-manager-unsigned-test` |
| 原日常开发环境 / 原签名身份 | `%APPDATA%\local-video-manager` |

验收时也可能指定独立目录，以实际启动方式为准。不同身份不自动合并、迁移；不要只凭窗口名称或相同版本号判断资料库相同。

### 更改数据存储位置（0.1.16 起支持）

1. 打开 **设置 → 数据存储位置**，可查看或打开当前数据目录。
   点击同一区域的 **查看目录说明**，即可在设置页展开用户版说明，了解各目录内容、迁移、备份和清理方法；说明随程序提供，离线可读，点击 **收起目录说明** 可关闭。
2. 点击 **更改位置**，选择存放位置。程序将在其中新建 `映匣数据-<当前身份目录名>` 专用文件夹；同名目录已经存在时不会覆盖或合并，请选择其他位置。
3. 核对预览中的原位置、新位置、文件数量和大小，点击 **迁移并重启**。程序退出后，在重新启动时复制并校验数据，完成后自动打开资料库。
4. 迁移包括数据库、设置、收藏与播放记录、应用下载的字幕、媒体缓存、应用日志和数据库备份。原视频、视频旁的字幕及用户导出的文件保持原位置。
5. 校验成功并启动新资料库后，自动清理已校验的原应用数据；发现原文件有变化时保留并提示。默认位置保留很小的 `data-location.json` 定位记录和 Electron 运行环境文件，请勿删除定位记录。

首次启动和已有用户升级均沿用原默认路径；升级同一身份的绿色包或移动程序文件夹后，继续读取所选数据目录。不同发行身份仍不自动合并资料库。迁移过程中请勿断电或断开磁盘，失败时继续使用原目录；目标位置可能留有未完成副本，确认当前资料库正常前请保留现场。

新目录磁盘不可用时，程序提示退出或“重新定位已有资料库”，不会自动新建空资料库。重新定位应选择包含 `library.sqlite` 的原有数据文件夹。迁移后不要再运行不支持目录定位的旧版本，以免其在旧默认位置建立另一份资料库。凭据同机迁移保留密文，换电脑或 Windows 用户后可能仍需重新登录。

### 备份应用数据

各目录和文件的用途、缓存与字幕区别、迁移标记、清理边界及备份方法见 [数据目录说明与维护手册](DATA_DIRECTORY_GUIDE.md)。维护者当前数据目录内另附同内容的 `数据目录说明.md` 阅读副本；该副本目前需在再次迁移后单独复制。

1. 正常关闭程序及相关窗口。
2. 复制整个当前应用数据目录到备份位置，保留 `library.sqlite`、设置、字幕、凭据和归属标记；迁移后另保留默认目录中的 `data-location.json` 定位记录。不要在数据库仍写入时只复制单个 SQLite 文件。
3. 原视频另做备份，缓存可以重建，但不能靠重建缓存恢复个人标记与原视频。
4. 备份可能包含私人路径、记录与受保护凭据，不公开上传。换电脑或 Windows 用户后可能需要重新配置凭据。

### 更新同一身份的绿色版

1. 备份并退出旧版。
2. 下载新 ZIP 与校验和，完整解压到**新文件夹**，避免混合新旧 DLL。
3. 运行新版，核对数量、收藏、来源与播放记录。
4. 更新自己的快捷方式，确认指向新版，再移除旧程序文件夹。

同一发行身份通常沿用数据，无需每次重新导入。数据库升级后要回退时，使用升级前完整备份，不直接用旧程序打开升级后的数据库。

### 移除程序

绿色 ZIP 无需运行卸载器；退出后删除自己解压出的程序文件夹即可，用户数据与源视频仍保留。需要清除个人数据时先核对并备份对应目录。程序移除、清理缓存、永久删除视频是不同操作。[免安装版说明](portable.md)。

## 10. 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 无法启动、缺 DLL | 完整解压、保留配套文件、适用 x64；重下载并校验，不删资料库 |
| 添加后找不到视频 | 目录、后缀、扫描错误、搜索条件、目录及包含子目录范围 |
| 有封面但时长待分析 | 网盘可能按需分析；列表查看可见预览或打开少量视频，不必反复全库扫描 |
| 黑屏、无声、进度不动 | 源文件能否读、网盘是否在线或缓冲；查看播放诊断，必要时试系统默认播放器 |
| `ECONNREFUSED 127.0.0.1:19798` | 当前环境是否运行 CloudDrive、端口是否正确；沙盒回环不连宿主机 |
| HTTP 地址不允许 | 非回环地址需有效 HTTPS，检查服务端与证书 |
| API 成功但无来源 | 是否挂载、Token 有无读挂载点权限、本地映射是否在当前电脑可见 |
| Token 已配置但替换框空白 | 正常保护，留空保留；换机器/用户或凭据损坏时重新输入 |
| 换程序文件夹资料库还在 | 正常，资料库在 Windows 用户目录 |
| 两个程序看到不同资料库 | 检查发行身份、快捷方式目标、隔离目录，不直接覆盖另一份库 |
| 搜不到合适字幕 | 修改片名、年份、季集、来源、语言；检查提供方权限与额度 |

## 11. 反馈问题

必要时在 **设置 → 诊断与日志** 先预览再导出，审阅后分享。不公开 Token、密码、整份数据库、私人视频或未经处理的目录清单。安全漏洞按 [私人报告说明](../SECURITY.md)反馈。
