# 普通用户安装教程

目前本轮结论尚未批准正式发布；只提供明确标记 `unsigned-test-build` 的隔离测试候选。
测试候选不能用于重要资料库，也不能作为当前正式安装的升级包。

## 下载与核对

1. 正式发布放行后，打开维护者批准的 [GitHub Releases](https://github.com/huntian0727/movie/releases)。
   选择 Windows x64 安装包，同时下载该版本 `SHA256SUMS.txt` 和 `build-metadata.json`。
2. 在 PowerShell 中运行以下命令，把示例文件名替换为实际下载的文件名：

   ```powershell
   Get-FileHash -Algorithm SHA256 -LiteralPath '.\拉面影视-版本号-x64-Setup.exe'
   Get-AuthenticodeSignature -LiteralPath '.\拉面影视-版本号-x64-Setup.exe' |
     Select-Object Status,SignerCertificate,TimeStamperCertificate
   ```

3. SHA-256 必须与该版本校验表完全一致。正式包签名应为 `Valid`，发布者应与维护者声明一致，并有可信时间戳。
   若校验不符、发布者不符或来源不明，停止安装。SHA-256 能检查文件一致性，不能单独证明下载来源可信。
4. 无证书测试包名称必须含 `unsigned-test-build`，其签名应为 `NotSigned`；它没有正式签名信誉。
   不要关闭 SmartScreen 或防病毒程序来绕过警告。

## 安装与首次使用

1. 系统需 Windows 11 x64；普通用户无需 Node.js/npm。关闭正在使用的同一测试身份应用。
2. 双击核验过的安装包，选择当前用户安装。安装目录由应用管理，不能放入个人视频或数据库。
   安装器拒绝不属于该身份的非空目录和未经审查的旧安装。
3. unsigned 测试包不自动创建正式版快捷方式。可从其安装目录运行 `拉面影视-unsigned-test-build.exe`。
   测试数据目录是 `%APPDATA%\local-video-manager-unsigned-test`，与正式资料库分开。
4. 先准备自行生成的短视频测试文件夹，在应用中添加来源目录，等待扫描、元数据和封面加载。
   检查搜索、播放、收藏、目录和异常页面。不要选择真实个人视频作为破坏性验收对象。
5. CloudDrive 为可选功能，只使用您有权限操作的账户；输入地址和 Token 后测试连接。
   视频内容不会因为创建 SQLite 索引而复制到安装目录。

## 备份与升级

正式资料路径仍为 `%APPDATA%\local-video-manager`，库文件名 `library.sqlite`。
退出应用后复制整个专属数据目录到安全备份位置，同时独立备份源视频。
DPAPI 凭据和机器/用户有关，换电脑后需重新输入；不要公开整个数据备份。

本轮测试包支持隔离身份的安装/同版本修复/卸载验收，不证明历史签名版升级安全。
旧 NSIS 卸载器可能递归清空原安装目录，因此新包拒绝自动调用未标记的旧卸载器。
旧版用户需等待维护者审查过的迁移方案；不要自行把数据库放进安装目录来迁移。
升级失败时保留目录、数据和备份，记录错误；不存在本轮已验证的自动回滚保证。

## 卸载和数据保留

从 Windows“设置 → 应用 → 已安装的应用”卸载对应身份。
卸载只移除该版本清单中的应用文件，不递归删除陌生文件，也不删除应用数据目录或源视频。
`--delete-app-data` 不被支持。卸载后若安装目录中有未知文件，目录可能仍然存在。
不要为清空目录而批量删除其内容；先确认是否放入了个人文件。

删除功能与卸载不同：应用内“永久删除”会删除选中的源文件，CloudDrive 操作也可能无法撤销。
大小/时长重复候选不代表字节相同。先用临时资料验证，不要把误删保护当作文件备份。

## 故障处理

启动失败时保留数据库，先查看版本、系统与脱敏日志；不要删除库文件解决 ABI 问题。
内嵌 mpv 缺失时使用 Chromium 支持的格式或系统默认播放器，完整 libmpv 不在本包内。
CloudDrive 凭据损坏时在设置页重新输入 Token；不要发送 Token 或密文/数据库到公开 Issue。
安全问题按照 [SECURITY.md](../SECURITY.md) 私人报告。

完整工程测试与未完成的实机项目见 [发布审计](public-release-audit.md)。

## 默认安全清理行为（2026-10-09 后的工作分支）

“重复候选”只依据大小/时长等元数据，不证明字节完全相同。公众默认下，当前页可执行“验证当前页”：先在说明窗口确认完整读取视频并计算 SHA-256；验证结果显示在“后台任务”。只有完整哈希相同的候选才允许在任务中心再次输入大写 `DELETE` 并确认永久删除。

之前的“批量删除当前页”“批量删除全部筛选结果”和单项快速删除 **不再提供为公众入口**。旧 `autoDeleteAfterVerification` 自动删除及已有快速 API 任务的继续/重试受到主进程保护，避免仅凭名称、大小、时长等缓存信息误删。旧任务需先取消并清除记录；如需大批量处理，应逐页进行完整校验。视频不可访问、哈希失败或核验身份变化时，默认不删除。注意：这些修改需要安装使用新候选包才会出现在桌面程序中，旧包仍是原有行为。

## 2026-10-09 原生媒体工具更新说明

后续测试分支改用相同来源的 FFmpeg/FFprobe 9.0.2-22，与旧 npm FFmpeg/FFprobe 包装层分离。新安装包必须明确标记 `unsigned-test-build`，与用户现有正式程序和数据目录隔离；正常用户无须安装 Node.js/FFmpeg 运行新包，工具随应用的 `resources/media-tools` 带入。**该工作分支仍未取得对公众分发的第三方许可与项目授权，所以测试包只能内部测试，不能公开下载。** 不要把旧安装器混成已升级版本。
