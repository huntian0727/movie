# ADR-002：低带宽重复候选规则

状态：Accepted（当前有效）

## Context

大量源文件位于访问缓慢的映射网盘。内容哈希或打开页面时读取文件会消耗带宽并造成明显卡顿。

## Decision

正式重复候选只按 SQLite 中已经缓存的精确文件大小和精确时长分组。页面查询不读取视频内容，不新增指纹计算；时长未知或元数据失败的文件不进入正式重复组。

永久删除前仍复查文件存在性、大小和修改时间。任何变化使旧计划失效，需要刷新后重新确认；规则只代表候选，不证明内容相同。

## Consequences

- 页面和重复扫描的网络读取最低，但可能出现同大小同时长的误候选。
- 历史 fingerprint schema/代码可为兼容性保留，但不能用于当前分组或文案。
- 用户必须能查看/播放候选，删除安全测试不能因性能优化而移除。
