# ADR-001：源视频是事实源

状态：Accepted（当前有效）

## Context

应用管理本地磁盘和映射网盘中的大量视频，但不能接管用户文件所有权，也不能因索引或缓存故障损坏源文件。

## Decision

源视频始终保留在原位置并作为事实源。SQLite 只保存索引、扫描状态和用户状态；封面/时间轴缓存是可删除、可重建的衍生物。文件操作只能在主进程通过受控 API 执行。

## Consequences

- 磁盘临时离线时采用 missing/异常软状态，不立即删数据库历史。
- 数据库记录不能单独证明文件可安全删除，危险操作必须复查当前磁盘状态。
- 缓存清理不得触碰源视频，数据库迁移和恢复不能移动用户媒体。
