# 目录浏览与局部扫描合并

## Context

目录浏览之前只显示 8 个视频预览，用户还需点击“查看全部”进入另一套列表；“刷新”只重读资料库索引，不能发现单个目录的文件变化。本轮开发前快照为 `2026-09-24_03-24-16-210_directory-workbench-scan`，检查点标签为 `checkpoint-20260924-112411-8b60acc-directory-workbench-scan`。

## Changes

- 点击资料库来源、最近目录或搜索结果后直接进入原有完整文件列表，沿用分页、搜索、排序和操作能力；目录路径、折叠子目录及范围选择置于列表上方，不再额外请求 8 项预览。
- 增加“扫描此目录 / 扫描此目录及子目录”操作，严格遵循当前“仅当前目录 / 包含子目录”的范围选择。目录浏览主页的“刷新”仍只更新已索引列表，打开目录不会自动扫描。
- 新增受来源路径约束的 IPC，并复用现有串行 ScanManager、目录 Snapshot 和元数据管线。局部扫描不覆盖来源级最近扫描时间或健康状态；仅在可读目录内执行缺失对账，失败或离线保留既有索引。
- 增加局部扫描边界、任务串行、页面范围一致性与 IPC 合约测试。未改数据库结构、播放与文件删除逻辑。

## Verification

- 定向扫描与页面测试：99 项通过。
- 初次完整门禁因工作区 SQLite 原生模块为 Electron ABI 而在 Node 数据库测试处失败；已通过 `npm rebuild better-sqlite3` 切回 Node 22 ABI。
- 最终完整门禁：75 个测试文件、692 项测试全部通过。Electron 原生及主进程 smoke 通过。
- Windows NSIS 安装包、产物检查、解包 smoke、独立安装器 smoke 全部通过。
- 从用户桌面 `Video Manager (Dev).lnk` 启动新构建：直接进入 6 视频完整目录列表，目录面板和局部扫描按钮显示正常；切换“仅当前目录”后按钮文案同步变更。未在用户真实资料库发起扫描。

## Risks and follow-up

- 局部扫描遵循现有元数据策略；挂载盘或 CloudDrive 的实际耗时仍由目录枚举与远端响应决定。
- 目录列表只展示已索引目录；尚未索引的空目录不会出现在子目录列表。
- 安装包未签名；用户当前桌面快捷方式指向新构建的 `release/win-unpacked`，无需改动快捷方式。
