# 本机隔离资料库的 115 API 真实验收

## Context

用户在 Windows 沙盒中配置 `http://127.0.0.1:19798` 后，测试连接报 `ECONNREFUSED`。该回环地址指向沙盒自身，而 CloudDrive 运行在宿主机。宿主机 HTTP 服务探测成功，但现有 Movie 客户端要求跨设备 API 使用 HTTPS；当时默认 HTTPS 端口 19799 未监听。未放宽端点校验、忽略证书校验或更改防火墙设置。

用户明确选择在本机隔离资料库验证 API，使用与 CloudDrive 同机的回环 HTTP 地址。验收于北京时间 2026-10-13 夜间开始，2026-10-14 完成。
