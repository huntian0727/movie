# 扫描异常全筛选选择与网盘失效记录提速

## Context

用户实际启动的桌面快捷方式仍指向旧的 `release/win-unpacked`，界面只能“全选本页”，且约 8 万条“文件不存在”记录仍按文件逐条访问 CloudDrive 和刷新数据库，处理速度不可接受。

## Changes

- 明确提供“全选全部筛选结果”并显示“不限当前页”，批处理提交筛选条件而不是当前页 ID。
- CloudDrive 缺失确认改为按远端父目录分组：同一目录无论包含多少条候选，只进行一次强制刷新完整列举。
- 所有远端目录均成功验证后，才用单个数据库事务批量解决异常和移除失效视频索引；取消、断线、权限或读取错误时不清理任何未验证记录。
- 批量读取异常记录并避免在“全部类型”查询中逐项查询视频，移除大批量处理中的二次方数据库刷新路径。
- 应用版本提升至 0.1.1，以便区分此前仍在使用的 0.1.0 桌面包。

- Node 22.23.1 针对性测试：PASS，3 个测试文件、21 项测试。

## Risks and follow-up

- 实际耗时由“文件条数”改为主要取决于“不同父目录数量”和 CloudDrive 目录列举速度；一个目录内 8 万条候选不再产生 8 万次 RPC。
- 当前运行中的旧版窗口不会被强制关闭；快捷方式切换后需从新版目标重新启动，旧窗口本身不会热更新。
- 安装包为未签名测试构建，正式发布仍需代码签名。
