## Context

视频数据表已经支持跨页勾选、选择全部筛选结果和导出，但缺少对应的批量删除入口。直接复用仅接受有限 ID 数量的普通批量删除接口，会导致“全部筛选结果”无法处理，并可能把大量记录加载到 Renderer。

## Changes

- 视频数据表新增“批量永久删除”按钮与确认对话框，支持手动勾选和全部筛选结果。
- 确认后当前页命中的记录立即从表格隐藏，删除异步执行，页面仍可继续浏览。
- 完成后显示成功数、失败数、释放空间以及首个失败原因，并自动刷新当前数据页。
- 新增 `video-data:delete` IPC；筛选结果 ID 在现有只读 Worker 中解析，不向 Renderer 加载完整结果集。
- 大批量永久删除安全检查改为每 500 个 ID 分块查询，避免 SQLite 变量数量上限，同时保留重复候选和活动任务占用检查。
- 继续执行现有永久删除安全契约：如果选择中包含重复候选，整批操作会在删除前被阻止。
