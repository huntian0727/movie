# 视频数据表交付

## Context

为几十万条视频资料库增加独立的数据表视图，用于快速检索、筛选、排序、分页选择和导出数据库中已有的视频信息。

## Changes

- 新增侧边栏“视频数据表”入口，以及从目录页进入数据表的入口。
- 展示文件名、目录、大小、时长、添加时间、来源与状态，并提供编码、分辨率、修改时间可选列。
- 支持文件名与完整路径搜索、资料库、来源、状态、目录及子目录、大小、时长和添加日期筛选。
- 支持 50、100、200 条分页、表头排序、跳页、全选本页和选择全部筛选结果。
- CSV 导出在独立只读 worker 中流式执行，并防止表格公式注入。
- 查询在独立只读 worker 中运行，打开页面不会访问视频文件、网盘或执行 FFprobe。
- 未修改数据库结构、扫描流程、播放流程或文件管理逻辑。

## Risks and follow-up

- NAS 来源依据 UNC 路径识别；普通盘符映射的 NAS 会显示为“本地 / 挂载盘”。
- 当前“选择全部筛选结果”用于 CSV 导出；后续增加批量写操作时必须重新核对筛选快照与操作范围。
- 添加时间使用现有 `imported_at` 字段，表示记录进入映匣数据库的时间。
