# AI 交付记录

这里保存每次 AI 开发或维护交付的短记录，让其他 AI 不依赖原始聊天即可知道最近发生了什么。

- 每次运行 `scripts/finish-and-push.ps1` 前，必须新增或修改一份日期开头的记录：`YYYY-MM-DD-short-topic.md`；`short-topic` 使用 ASCII 字母、数字、点、下划线或连字符。
- 使用 `TEMPLATE.md`，记录背景、实际修改、真实验证、风险与后续；未执行的验证写 `NOT RUN` 或“需要验证”。
- 不粘贴令牌、用户媒体路径、数据库内容、完整日志或大段终端输出。
- 同一任务的修正可继续更新同一记录；已经提交后发生的新交付应创建新的记录，形成可追溯时间线。
- 精确代码差异和 Commit 仍以 Git 为准；此目录用于快速交接，不替代 CHANGELOG。

近期记录按文件名倒序阅读。历史任务没有逐条补写，需结合 `CHANGELOG.md`、`REPORT.md` 和 Git 历史。
