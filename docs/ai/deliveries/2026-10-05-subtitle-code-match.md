## Changes

- shared/subtitleQuery.ts 统一编号提取与普通片名清理；带明确系列编号的文件优先使用该编号，保留用户明确编辑的查询。支持大小写、下划线、全角字符和有限系列紧凑形式。
- 普通片名、年份、季集和 codec 字段保持普通查询；非已知系列的空格/点号加数字不当作编号，避免 Room 104、Studio.666、电影年份等误识别。
- 迅雷遇到编号查询时发送纯编号，不用完整标题替代。主进程所有来源候选都必须在 title/release/filename 中有相同完整编号，明确其他编号和未标编号均不推荐；编号不同位数不做子串匹配。编号匹配只说明身份线索，不保证同步。
- 快捷面板显示实际搜索词；没有编号相符候选时明确提示编号及换来源，不用姓名近似结果填充。
- 字幕文件/凭据/播放器链未改变，没有自动下载、内容生成或批量动作。

## Risks and follow-up

候选缺少可核实编号时会隐藏，可能遗漏正确但无编号的字幕；用户可改用其他查询或来源。编号识别属于保守文件名规则，不能涵盖所有出版编号。普通文字片名保留原规则；新来源仍须经过主进程过滤。

字幕来源的可用性、返回语言线索及网站译文质量等既有限制保持。上线需以最终 Commit 重新打包并验证原桌面快捷方式，不能仅交付源码。回滚走正常修复/revert，不强制推送。
