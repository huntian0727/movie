# 映匣 UI 增量优化 V1 ASCII 原型

## 原型说明

本原型用于确认信息顺序和交互位置，不代表最终像素尺寸。两个页面均复用现有左侧导航、顶部工具栏、深色主题和按钮体系。

字符说明：

- [ ] 表示按钮或可点击区域。
- { } 表示选择器或筛选器。
- > 表示进入其他页面。
- 数值均为示例，不是产品真实数据。

## 视觉层级对照

| 层级 | 资产中心 | 播放诊断 |
| --- | --- | --- |
| 一级 | 核心指标带 | 规则结论 |
| 二级 | 扫描状态、需要处理 | 文件信息、播放分析 |
| 三级 | 资料库分页列表 | 视频和音频字段 |
| 四级 | 更新时间、字段说明 | 证据来源、未验证项 |

## 共同状态规则

- 首次加载使用结构骨架，不使用居中全屏 spinner。
- 后台刷新保留旧内容，不闪白、不折叠布局。
- 错误显示在发生错误的区块内。
- 未知、没有、失败必须使用不同文字。
- 自动动画为零，旋转图标只用于真实进行中的刷新或任务。
- 按钮按下提供轻微位移反馈，并遵守 prefers-reduced-motion。

## 原型验收

- 两个页面在 1440px 宽度下首屏显示核心结论和主要操作。
- 没有商业 SaaS 常见的悬浮卡片墙、图表装饰或虚假百分比。
- 每个关键数字和状态都有清晰去向。
- 播放分析始终带有规则结论免责声明。
- 页面入口和跳转目标不复制现有业务逻辑。
