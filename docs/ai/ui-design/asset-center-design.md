# 资产中心页面设计

## 设计定位

资产中心是个人视频资料库的状态总览，不是商业运营仪表盘。页面必须让用户在十秒内知道：资料库有多大、来源是否可用、扫描是否正常、下一步最值得处理什么。

设计参数：

- DESIGN_VARIANCE: 3，保持现有页面秩序，不做不对称装饰。
- MOTION_INTENSITY: 2，仅保留 hover、按压和加载状态反馈。
- VISUAL_DENSITY: 8，优先在一个桌面视口中呈现有效信息。
- 视觉基础：沿用现有深色主题、Segoe UI Variable、橙红强调色和 Lucide 图标。
- 不新增 UI 框架，不使用渐变、玻璃效果、发光、插图或装饰动画。

## 导航位置

在左侧主导航顶部增加“资产中心”，位于“所有视频”之前。

建议导航顺序：

    资产中心
    所有视频
    收藏
    待删除
    最近播放
    播放诊断
    扫描异常
    重复项

V1 上线后仍可暂时保持“所有视频”为默认打开页面。稳定后再单独决定是否将资产中心设为默认页，避免悄悄改变现有使用习惯。

## 页面布局

页面使用四个纵向区域。顶部工具栏固定，其他区域随内容滚动。

### 顶部区域

左侧：

- 标题：资产中心。
- 副标题：共 320,243 个视频，数据更新于 16:20。

右侧：

- “刷新数据”图标按钮，只刷新数据库汇总。
- 刷新中显示按钮内部旋转图标，不遮挡页面。
- 页面有旧数据时继续显示旧数据，禁止刷新时整页变空。

标题下方只在需要时出现一条状态提示：

- 正常：不显示提示条，减少视觉噪声。
- 需关注：显示一条黄色提示，内容为优先级最高的问题。
- 严重异常：显示一条红色提示，并提供明确处理入口。
- 部分数据读取失败：显示“部分数据未更新”，其他区域继续可用。

### 核心数据区域

四项核心指标使用一条连续指标带，不做四张悬浮卡片：

| 指标 | 主值 | 补充信息 | 点击行为 |
| --- | --- | --- | --- |
| 视频总数量 | 有效视频数量 | 缺失记录数量 | 进入“所有视频” |
| 总容量 | 有效视频总字节格式化值 | 待删除可释放容量 | 滚动到资料库列表并按容量降序 |
| 视频来源 | 已启用来源数 | 本地、NAS、CloudDrive 构成 | 滚动到资料库列表 |
| 在线状态 | 最近状态正常数 / 已启用数 | 说明“基于最近扫描” | 资料库列表切换到异常来源筛选 |

指标带规则：

- 四项之间使用单条竖向分隔线，不给每项增加独立边框和阴影。
- 主值使用 26-30px 半粗数字，标签使用 12px 次级文字。
- 数字使用等宽数字特性，更新时避免宽度跳动。
- 可点击项使用完整按钮语义和 focus 状态，不只依赖鼠标。

### 状态区域

状态区域采用左右两栏，左侧约 60%，右侧约 40%。窗口宽度不足 1100px 时改为上下排列。

#### 扫描状态面板

面板标题：扫描状态。

内容优先级：

1. 当前扫描任务。
2. 最近一次完成任务。
3. 扫描异常数量。

当前有任务时显示：

- 资料库名称或路径。
- 当前阶段：等待中、发现目录、比较变化、处理媒体、重试异常、已暂停。
- 已处理视频和目录数量。
- 开始时间和持续时间。
- “查看后台任务”按钮。

当前无任务时显示：

- “当前没有扫描任务”。
- 最近扫描完成时间。
- 最近结果：新增、更新、缺失、失败数量。

扫描异常行始终可见：

- 扫描异常数量。
- 点击后进入 ScanFailuresPage。

#### 健康状态面板

面板标题：需要处理。

使用四行操作列表，每行包括状态名称、数量、一行解释和右箭头：

| 状态 | 字段 | 点击目标 |
| --- | --- | --- |
| 元数据缺失 | pending + failed 的有效视频数 | 所有视频的元数据状态筛选；筛选未实现前禁用跳转并显示说明 |
| 播放风险 | 规则判定为 MPV 优先或信息不足的视频数 | PlaybackDiagnosticPage 的风险筛选 |
| 重复候选 | 当前重复候选组数 | DuplicateGroupsPage |
| 文件缺失 | is_missing = 1 的记录数 | ScanFailuresPage 的文件不存在筛选 |

列表只使用行间距和组边框，不给每一行套卡片。

### 列表区域

标题：资料库。

工具栏：

- 搜索：按名称或路径。
- 类型：全部、本地、NAS、CloudDrive、挂载盘。
- 状态：全部、正常、需关注、异常、已停用。
- 排序：容量、视频数、最近扫描、异常数、路径。

资料库必须服务端分页，默认每页 30 条，允许 50 或 100 条。禁止一次返回所有来源。

#### 列表列

| 列 | 内容 | 展示规则 |
| --- | --- | --- |
| 资料库 | 名称或路径 | 第一行显示末级名称，第二行显示完整路径并中间省略 |
| 类型 | 本地、NAS、CloudDrive、挂载盘 | 使用文字和同一套 Lucide 图标 |
| 视频 | 有效视频数 | 右对齐 |
| 容量 | 有效视频容量 | 右对齐 |
| 来源状态 | 最近状态 | 正常、需关注、异常、已停用；附“基于最近扫描”提示 |
| 最近扫描 | 时间 | 同日显示时间，其他日期显示日期和时间 |
| 问题 | 异常、缺失、元数据失败汇总 | 无问题时显示短横线 |

点击资料库行进入现有文件夹视图，并选择对应来源根目录。问题数量可单独点击进入相应异常筛选。

## 来源类型定义

当前数据库可以可靠识别 CloudDrive，也能通过 UNC 路径识别部分 NAS。映射盘可能无法仅根据数据库路径区分本地磁盘和网络盘。

V1 展示规则：

- providerType 为 clouddrive：显示 CloudDrive。
- UNC 路径：显示 NAS。
- 普通盘符且无法确认介质：显示“本地 / 挂载盘”。
- 如果后续增加只读驱动器类型检测：再细分本地和挂载盘，不在 UI 层猜测。

“在线状态”不是实时网络监控。它表示最近一次扫描或 API 检查是否成功，字段旁必须显示“基于最近扫描”。

## 字段列表

### 页面总览

| UI 字段 | 建议数据字段 | 说明 |
| --- | --- | --- |
| 视频总数量 | library.activeVideoCount | 不包含缺失记录 |

| 待删除容量 | library.pendingDeleteBytes | 只作为补充信息 |

| UI 字段 | 建议数据字段 |

## 交互说明

### 跳转矩阵

| 用户操作 | 目标 |
| --- | --- |
| 点击视频总数量 | LibraryShell 的 all 视图 |
| 点击总容量 | 本页资料库列表，按容量降序 |
| 点击视频来源 | 本页资料库列表顶部 |
| 点击在线状态 | 本页资料库列表，筛选需关注和异常 |
| 点击扫描异常 | ScanFailuresPage |
| 点击重复候选 | DuplicateGroupsPage |
| 点击播放风险 | PlaybackDiagnosticPage 的风险筛选 |
| 点击文件缺失 | ScanFailuresPage 的 missing 筛选 |
| 点击资料库行 | LibraryShell 的 folder 视图 |
| 点击当前扫描任务 | 现有后台任务面板 |

所有跳转使用现有页面回调或新增 UI 导航参数。资产中心不复制扫描、重复清理或文件操作逻辑。

### 刷新行为

- 首次进入并行加载 overview 和资料库第一页。
- 刷新按钮只读取 SQLite 聚合，不触发目录扫描。
- Domain Event 在 300-500ms 内合并，页面不可见时只标记数据过期。
- 在途请求复用，迟到响应通过 revision 或请求序号丢弃。
- 单个区域失败时保持其他区域可操作。

## 页面状态

### 加载

- 指标带使用固定宽度骨架。
- 状态区使用与最终内容一致的行骨架。
- 列表仅显示 6-8 行骨架，不使用全屏 spinner。

### 空状态

- 没有资料库：显示“尚未添加资料库”和“添加本地文件夹”“通过 API 添加”两个现有操作入口。
- 有资料库但没有视频：显示来源数量与最近扫描状态，提示前往对应资料库。
- 没有异常：不显示庆祝图形，只显示“目前没有需要处理的问题”。

### 错误

- overview 失败：保留最近成功快照并标注更新时间。
- 来源列表失败：只在列表区域显示重试按钮。
- 部分统计不可用：显示“暂无数据”，不显示 0。

## 视觉规范

- 页面背景继续使用 #111212，面板使用 #181a18 或 #191a19。
- 主强调色继续使用 #e4573d，仅用于当前导航、关键操作和焦点。
- 正常状态使用现有低饱和青绿色，警告使用 #e8a744，错误使用 #ff7b68。
- 状态必须同时显示文字和图标，颜色不是唯一信息。
- 控件圆角 6px，面板圆角 10-12px，状态标签允许 pill。此为现有系统的明确分层规则。
- 面板不使用投影。层级通过背景、间距和单条边框表达。
- 不增加自动入场动画。数据更新只允许 120ms 以内颜色或透明度反馈，禁止数字滚动动画。

## 窗口适配

- 1440px 以上：状态区双栏，资料库显示全部列。
- 1100-1439px：状态区仍可双栏，隐藏资料库次要问题摘要。
- 900-1099px：状态区上下排列，资料库隐藏容量或最近扫描中的一个次要列。
- 小于 900px：核心指标改为 2 × 2，资料库行改为紧凑摘要列表。

这是 Windows 桌面应用，不为移动触控界面重新设计。

## 性能验收

- 打开资产中心时不访问视频文件、目录或 CloudDrive。
- renderer 不接收全量 VideoRecord 或全量来源。
- overview 响应保持固定体积，目标小于 16 KB。
- 来源列表每页最多 100 行。
- 任何卡片点击都应在 100ms 内产生视觉反馈。
- 连续扫描事件不会造成重复请求、整页重排或闪烁。
