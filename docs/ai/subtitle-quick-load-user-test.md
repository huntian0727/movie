# 快捷字幕使用与用户测试

1. 打开影片，点右上角“找字幕”，直接开始搜索。默认迅雷，优先推荐带中文/双语线索的候选；首次字幕仍需点选。
2. 右侧先显示 3 个推荐版本。点“下载并使用”，成功后面板收起；播放控制区出现“换字幕”“提前 0.5 秒”“延后 0.5 秒”“关闭字幕”。提前使字幕更早出现，延后使字幕更晚出现。
3. 没找到合适的版本，点“更多字幕 / 修改片名”：可改为英文片名、补年份/季集，切换语言和来源，查看全部结果。来源/语言会记住；已提交的片名在当前应用会话内记住。
4. 关闭再打开面板会复用 5 分钟内相同影片版本/片名/来源/语言的搜索结果；“重新搜索”强制刷新。失败不缓存，影片文件变化后结果失效。超出主进程候选缓存的旧结果可能提示重新搜索。
5. 本轮下载过的同一来源字幕可复用已保存文件，不重复下载，并保留当前偏移。旧版保存且没有来源关联标记的字幕可从“已保存字幕”选择。已选字幕在下次播放时自动恢复。

请重点试：首次查找是否少了操作；关闭后重开是否快；换字幕后是否同步；连续点偏移按钮是否有明确反馈；全屏/窗口模式右侧面板是否挡住画面。反馈影片名称、字幕来源和候选版本、期望行为及实际现象即可，无需提供密钥。

实际影片语言、匹配和时间同步由用户测试。字幕网站响应速度取决于网络，推荐顺序不能保证同步；迅雷语言信息可能只是文件名线索。外部播放器仍需通过高级面板导出并手动载入。同目录字幕自动发现不属于这一版。
