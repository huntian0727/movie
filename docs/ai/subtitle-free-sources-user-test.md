# 无密钥字幕来源：用户测试说明

开发版本增加迅雷（默认）和 Subtitle Cat（可选），不需要先注册或填写 API Key。真实影片匹配、译文与播放体验由用户验收，开发者技术检查不能替代。

1. 从桌面“拉面影视”快捷方式打开程序，播放一部没有字幕的影片，点击顶部“字幕”。
2. 保持来源“迅雷字幕”、语言“不限语言”，点击“搜索字幕”。若无结果，修改搜索框为英文片名＋年份，或剧名＋S01E02，再搜索。
3. 核对候选名称/发行版本，点击“下载并使用”。观察是否显示字幕、实际语言是否正确、开始和中段是否同步。名称匹配分不能保证同步，“可能中文”仅为文件名线索。
4. 调节时间偏移；正数让字幕晚出现，负数让字幕早出现。关闭面板、切换视频再返回、退出重开后检查是否仍选中该字幕。
5. 若迅雷没有合适候选，单独选择 Subtitle Cat，选择“中文”或“英语”后搜索。网站无对应语言下载时会明确提示；译文可能来自机器翻译。该来源不支持可靠的双语筛选。
6. 可测试关闭字幕、切换已保存版本及导出。外部播放器需手动加载导出的文件。

反馈建议记录：来源、搜索词、候选名称、实际语言、是否显示、偏移值、错误提示和触发步骤。无需提供账号密钥；原 ASSRT/OpenSubtitles 的配置继续保留。
