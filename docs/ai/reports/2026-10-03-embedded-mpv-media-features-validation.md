# 内嵌 MPV：短时媒体功能与卡流验证

## 结论与范围

用户明确取消本阶段长时间播放测试，留到后续正式使用观察。本轮只补充隔离原型的短时证据，不接入正式播放器，不修改 `src/`、数据库、扫描、文件管理、安装包或快捷方式。

四个真实 libmpv 场景重复两轮全部通过；内嵌/外挂中英文 SRT 和隐藏字幕的三个真实窗口画面符合预期。默认四种格式的已有控制回归也全部通过。这支持继续设计正式集成方案，**不等于已经发布内嵌播放器，也不能保证所有格式可播放**。

## 场景设计与判据

中性双音轨 MKV：12s、640×360/24fps、H.264、AAC 48kHz（440Hz/880Hz）、内嵌 SRT；文件名包含中文与空格，2,908,595 bytes。外挂 SRT 使用另一固定标记。分片 MP4：20s、H.264/AAC、4,689,673 bytes。

只在可信 CLI 媒体验证模式开启宿主音轨/字幕命令。轨道 ID 按媒体类型匹配，成功 ack 不算轨道切换成功；字幕选择要同时检查标记布尔值，关闭后检查轨道未选中或可见性为 no。MPV 的 `sub-text` 即使隐藏字幕也可返回文本，所以“存在字幕文本”不能证明实际画面可见。[MPV 属性与输入契约](https://github.com/mpv-player/mpv/blob/master/DOCS/man/input.rst)

外挂采用 `sub-add … cached`，禁用自动搜字幕，确保只加载指定的中性测试文件。未向 renderer 开放任意路径，采样不记录实际字幕内容/轨道标题/外挂文件名。[MPV 手册](https://mpv.io/manual/master/)

回环 HTTP 发送完整前两个片段共 446,000 bytes，保持响应未结束；等待文件已加载且实际时间推进，然后等待 `paused-for-cache=yes`。恢复要求取消暂停、无 seek、无缓存等待、时间推进超过 0.6s；退出要求队列清空且自有宿主结束。自动模式关闭实验窗口后台计时器节流，手动模式仍保持默认。

## 实测结果

| 场景 | 第一轮 | 复测 | 证明范围 |
| --- | --- | --- | --- |
| 两条音轨切换及禁用 | PASS，3,587ms | PASS，3,371ms | 两轨实际 selected、WASAPI/48kHz、时间推进；非听感验证 |
| 内嵌→外挂→隐藏→关闭→恢复 | PASS，2,328ms | PASS，2,310ms | 对应轨道/标记/可见性状态 |
| 中途卡流与恢复 | PASS，恢复 622ms | PASS，恢复 674ms | 1.813s 左右进入真实缓存等待；renderer 心跳持续；补流后继续播放 |
| 卡流期间退出 | PASS，241ms | PASS，236ms | 均自然结束，未触发强杀，队列为空 |

恢复耗时包含判据所需的 0.6s 实际推进，不是纯解码启动耗时。

自动轮全程 main 100ms 心跳最大额外延迟 54.9/33.1ms，renderer 14.1/11.1ms；不代表正式应用点击延迟保证。原始匿名报告：`media-features-first.json`、`media-features-final.json`，均 `pass=true`、`failures=[]`。

真实窗口视觉验证（电脑操作技能）：

- `embedded`：暂停在 2s，画面底部显示 INNER 英文及完整中文内嵌字幕，控件未被覆盖。
- `external`：同位置显示 EXTERNAL 英文及完整中文外挂字幕，未同时显示旧内嵌字幕。
- `hidden`：同位置保留视频画面，无字幕显示。
- 每次从窗口点击“退出实验”，宿主自然结束分别为 177/162/189ms。JSON 只记录运行状态，不自动产生视觉 PASS；上述结论来自实际截图观察。

默认模式回归：H.264/AAC、HEVC/AAC、HEVC/DTS、VP9/Opus 四种 12s 中性样本全部通过。五次突发 seek 合并为 `[2,10]`，混合 seek/旋转最终正确，恢复/重新加载清队列/seek 期间退出正常；自然退出 181–187ms。报告 `media-default-controls-regression.json`：`pass=true`、`failures=[]`。两轮、三项视觉及四格式回归记录的宿主 PID 最后均已退出。

## 未验证事项与后续

1. 长时间播放/4K 持续性能/长期内存：**NOT RUN，按用户要求延期**。
2. 实际听感、声音设备切换、主观音画同步：NOT RUN。WASAPI 初始化不等于扬声器输出已人工确认。
3. ASS/PGS、样式/字幕偏移、多音轨特殊格式、HDR 色彩：NOT RUN。SRT 三种视觉状态不等于完整字幕矩阵。
4. 本轮卡流仅是回环 HTTP 短暂停供，不是真实 CloudDrive 掉线。无限期中途停供的统一截止/提示策略尚未实现；旧 30s 上限只覆盖首次加载。
5. 强制杀死卡住宿主的分支、物理键盘/输入法、跨显示器 DPI、DLL 发布许可证与安装器：仍需有界验证或审查，不以本轮自然退出代替。
6. 建议下一步先冻结原型接口并审查发布许可证/正式对接方案，再决定是否加入可回退的内嵌 MPV 模式；不自动改现有播放策略或删除外部播放器回退。

桌面版本尚未交付；本轮未更新正式安装包/快捷方式。
