# 桌面端手动测试清单

## 测试准备

- 启动 Vite：`npm run dev`
- 启动桌面端：`npm run dev:electron`
- 准备至少 6 个样本视频：
  - `.mp4`
  - `.mov`
  - `.webm`
  - `.mkv`
  - `.avi`
  - 一个较长视频，用于测试进度条 hover 预览
- 如需验证 mpv fallback，确认 `mpv` 已安装并加入 PATH。

## 1. 启动与基础性能

- [ ] 桌面端能打开主窗口。
- [ ] 主窗口标题正确。
- [ ] 视频很多时主窗口没有明显卡死。
- [ ] Electron renderer 内存保持在可接受范围，没有持续快速增长。
- [ ] 启动同步不会让 UI 长时间无响应。

## 2. 添加文件夹与扫描

- [ ] 点击添加文件夹可打开系统目录选择。
- [ ] 选择包含视频的目录后，视频出现在列表。
- [ ] 视频大小显示正确。
- [ ] 视频时长显示正确。
- [ ] 视频分辨率或格式显示正确。
- [ ] 手动重新扫描不会产生重复记录。
- [ ] 删除磁盘上的一个视频后重新扫描，该视频不再出现在普通列表。
- [ ] 缺失视频出现在设置页缺失文件列表。

## 3. 列表、搜索、排序、分页

- [ ] 所有视频视图显示全部非缺失视频。
- [ ] 收藏视图只显示收藏视频。
- [ ] 最近播放视图只显示播放过的视频。
- [ ] 文件夹视图只显示该文件夹视频。
- [ ] 搜索文件名能正确过滤。
- [ ] 按文件名排序正确。
- [ ] 按大小排序正确。
- [ ] 按时长排序正确。
- [ ] 升序/降序切换正确。
- [ ] 默认每页 100 条。
- [ ] 可切换每页 200 条。
- [ ] 可切换每页 300 条。
- [ ] 上一页/下一页可用状态正确。
- [ ] 切换搜索、排序、视图后回到第一页。

## 4. 封面预览图与缓存

- [ ] 网格卡片显示视频封面。
- [ ] 首次显示时可以接受短暂生成延迟。
- [ ] 第二次进入同一页，封面加载明显更快。
- [ ] 清理缓存后封面能重新生成。
- [ ] 封面生成失败时显示默认占位，不显示破图。
- [ ] 大量封面生成时 UI 不明显卡顿。

## 5. 独立播放窗口

- [ ] 点击视频播放后打开独立播放窗口。
- [ ] 主窗口仍停留在视频库页面。
- [ ] 再点击其他视频时复用同一个播放窗口。
- [ ] 复用窗口后播放内容替换为新视频。
- [ ] 关闭播放窗口不关闭主窗口。
- [ ] 播放窗口重新打开正常。

## 6. 播放能力

- [ ] `.mp4` 可播放。
- [ ] `.mov` 可播放或给出明确 fallback。
- [ ] `.webm` 可播放。
- [ ] `.mkv` 可通过 mpv 播放，或在 mpv 不存在时显示明确错误。
- [ ] `.avi` 可通过 mpv 播放，或在 mpv 不存在时显示明确错误。
- [ ] 原生播放器失败时会自动尝试 mpv。

## 7. 播放控制

- [ ] 播放/暂停可用。
- [ ] 快进可用。
- [ ] 快退可用。
- [ ] 音量调整可用。
- [ ] 静音可用。
- [ ] 全屏可用。
- [ ] 上一部可用。
- [ ] 下一部可用。
- [ ] 没有上一部时上一部按钮禁用。
- [ ] 没有下一部时下一部按钮禁用。
- [ ] 空格键播放/暂停。
- [ ] 左右方向键快退/快进。

## 8. 进度条 hover 预览

- [ ] hover 到进度条任意位置，显示对应时间。
- [ ] hover 到视频中段，时间计算正确。
- [ ] hover 后能显示预览帧。
- [ ] 第一次 hover 生成慢时 UI 不阻塞。
- [ ] 第二次 hover 同一时间附近命中缓存。
- [ ] 预览帧生成失败时仍显示时间，不显示破图。
- [ ] 快速移动鼠标不会导致 UI 卡死。

## 9. 收藏

- [ ] 在列表点击收藏，状态立即变化。
- [ ] 在播放窗口点击收藏，状态变化。
- [ ] 收藏视频出现在收藏视图。
- [ ] 取消收藏后从收藏视图消失。
- [ ] 重启应用后收藏状态保留。

## 10. 删除与重命名

- [ ] 重命名弹窗显示当前文件名。
- [ ] 重命名保留原扩展名。
- [ ] 重命名后磁盘文件名变更。
- [ ] 重命名后列表显示更新。
- [ ] 删除前出现确认。
- [ ] 确认删除后磁盘文件被删除。
- [ ] 删除后列表移除该视频。
- [ ] 文件被占用或权限不足时显示错误。

## 11. 最近播放

- [ ] 播放任意视频后出现在最近播放。
- [ ] 最近播放按播放时间倒序。
- [ ] 同一个视频重复播放只保留一条。
- [ ] 再播放其他视频后顺序更新。
- [ ] 重启应用后最近播放保留。

## 12. 设置与维护

- [ ] 默认递归扫描设置可切换。
- [ ] 启动同步设置可切换。
- [ ] 快进/快退秒数设置可修改。
- [ ] 播放策略设置可修改。
- [ ] 缓存位置显示正确。
- [ ] 清理缓存后缓存目录清空并重建。
- [ ] 清理缓存后封面和进度预览可重新生成。
- [ ] 缺失文件可从资料库移除。

## 失败记录模板

发现问题时按以下格式记录：

```text
功能：
步骤：
预期：
实际：
严重程度：P0 / P1 / P2
备注：
```
